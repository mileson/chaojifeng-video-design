# 讲解配音的声音方向

适用：带旁白的讲解、说明、宣传和解读片，包括产品说明、知识讲解、访谈解读和教程。先定“谁在讲、讲多快、情绪怎么起伏、配乐和音效怎么托住他”，再选工具。声音的授权、参考样本与状态梯度见 [讲解导演](explainer-narration.md)，本机配音见 [Qwen 配音接入](qwen3-tts-narration.md)，访谈解读的铺底与音效排程见 [访谈解读·声音](interview-commentary-direction.md#声音)，通用混音与节奏见 [声音与节奏](sound-and-rhythm.md)。

目录：已确认的倾向 · 默认取向 · 把“更有激情”落成做法 · 配乐与音效 · 从听感反馈到重做 · 取样与拼接的坑 · 验收与边界

## 已确认的倾向

下表是用户听片后的反馈，跨说唱科普、电商科普、访谈解读和产品说明四类作品。他用听感和方向给反馈，没有给过可测的数字。

| 日期 | 反馈要点 | 作品 |
| --- | --- | --- |
| 2026-10-20 | 说唱“声音太弱”，要有激情感、节奏感，语速相对快；随后要“更饱和、更清爽”；换了声音，卡点要跟着整套重排 | 说唱科普 |
| 2026-10-20 | 声音与伴奏要有欧美新锐创业公司那种创新、年轻的感觉；旁白用本人音色；开头 5 秒就要有强节奏感与叙事感 | 电商科普 |
| 2026-11-05 | 配音用本人音色并要“更具感染力”；本地参考音色成片之后，改要求用云端 API 生成；音效要像对标片那样落在不同的情绪点上；背景音乐按场景不同，且不能影响讲话 | 访谈解读 |
| 2026-11-05 | 通用声音“单调”，语速要“快一些”，要“富有激情”，用本人音色复刻 | 产品说明 |

稳定下来的四条取向（表里是用户的话，下面是整理，没有逐条经用户确认）：

1. **音色**：超级峰自己的作品，旁白用他授权的本人声音，不用通用合成声。
2. **语速**：偏快、紧凑；慢条斯理的通用声被判单调。
3. **激情**：有起伏、有感染力，饱满而清爽，不是平铺直叙地念稿。
4. **配乐与音效**：托住人声而不压人声；音效落在情绪点，不是每个动作都响；随场景和章节换；开头 5 秒就有节奏与叙事。

用户的话是听感，没有数。拿到这类反馈，先翻成可量的代理指标并说明代理的局限（见“从听感反馈到重做”），不要把“量过了”写成“听起来对了”。

## 默认取向

没有另行指定时：

- **谁的声音。** 超级峰自己的产品、账号和内容，讲解默认用他已授权的本人声音，不必每次等他点名。其他使用者换成自己的获准声音，不把本人音色当通用默认。替第三方制作、授权不明，或口播文字不能发给云端时，用通用声，并在交付里写明它偏平、语速偏慢。授权、哈希和状态梯度沿 [讲解导演](explainer-narration.md)。
- **走哪条路线。** 用户指定的优先。用户在本地 Qwen3-TTS 的本人音色成片之后，要求改用云端 API 生成；随后的产品说明片他只说“用超级峰的音色去复刻”，沿用了同一条云端克隆路线。所以本人声音默认走已有的云端克隆音色（火山声音复刻 2.0）；本机 Qwen3-TTS 参考音色是无网络、无预算或口播文字不便外发时的备选。“云端更有激情”没有做过对比听审，只是沿用了用户的选择。云端路线是收费路线：口播文字会发给服务商，不发录音，不新建音色；先写明预算上限并逐次记账，凭证只经保险库读取，不进项目、文档和日志；本地路线失败时不悄悄切换，先报告。
- **语速起点。** 从第二版的数字出发：整体约 5.8 字/秒（含停顿），有声段约 6.7 字/秒。第一版的 3.7（有声段 4.3）被用户判慢。第二版用户尚未听审确认，是起点不是标准，听完再调。量法：字数 = 汉字个数 + 每个英文词或数字串记 1；整体 = 字数 ÷ 首字到末字的时间，有声段 = 字数 ÷ 去掉停顿后的有声时长。专名、数字和否定词略放慢，快不等于挤，清晰优先。
- **口吻。** 文案按 `chaojifeng-creator-style` 写，事实、数据和个人经历照账本，无依据的不写。激情主要靠声音处理，不靠在稿子里堆感叹号（实测感叹号让配音更慢，起伏也没有变宽）。

## 把“更有激情”落成做法

下面是在云端克隆音色上量过的结果（2026-11-05，一条 63 秒、16 段口播的产品说明片；接口参数以服务商当前文档为准，这里只记实测）。

| 手段 | 实测 | 用法 |
| --- | --- | --- |
| 提语速 `speech_rate` | 生效，+10 与 +15 都按预期加快 | 首选；各取样混用 +10 与 +15 |
| 音高 `post_process.pitch` | 生效，−3、0、+3 半音时音高中位约 110、128、157 Hz | 小幅上移 +1 半音；±3 偏离过大没有采用，是否仍像本人没有听审 |
| 同一请求多取样 | 同一句重复请求，时长上下浮动 15%–20%，起伏也不同，像“抽卡” | 每段 6 个取样（3 个 +15、3 个 +10），客观择优，规则见下 |
| 人声提亮 | 后期均衡 | 2.8 kHz 抬 2.5 dB、5.5 kHz 抬 1.5 dB、9 kHz 以上高架抬 1 dB；单声道人声文件先定约 −17.5 LUFS 再混 |
| 配乐速度 | 乐床由 92 提到 108 BPM，鼓点在开场之后的第一章进入 | 与语速同向，整体能量跟着抬 |
| 情绪提示文本 `context_texts`、`<cot>` 标签、模型子型号参数 | 对语速、音高、能量都没有可测影响 | 不再试，除非换了音色或模型 |
| 感叹号、多加逗号 | 语速变慢，起伏没有变宽 | 不拿它们“加情绪” |
| `emotion` 参数 | 按服务商文档面向预置的多情感音色，没有对克隆音色实测 | 克隆音色不依赖它 |

本机 Qwen3-TTS 路线加速按其接入指南第 4 节（`atempo` 后处理，倍率按本次校准），起伏同样靠多取样择优。

**择优规则（每段 6 个取样）**：先看回听转写与稿件的差异（同音字归一后），入围条件是不超过该段最佳取样 +0.06 且不超过 0.16；入围者按“起伏”（音高标准差的半音数、电平范围的分贝数）减“语速罚”（目标 6.5 字/秒，低于 6.5 或高于 7.6 都罚）再减“连续性罚”（音高中位偏离全片中位超过 5%）打分，同分取更短的。分段用意思完整的段落，本次约 356 字拆成 16 段，每段约 22 字，抽到差的取样代价小，也方便只重做某一段。

**上限与根治**：以上只能在现有克隆音色的表现区间里挑。起伏仍平，多半是训练素材本身平，根治办法是用情绪饱满的新录音重新训练：要本人录音、明确授权，训练次数有限，不要自行触发。

## 配乐与音效

- **人声永远是主角**，配乐宁可轻。说明片的乐床电平与闪避参数见 [真实界面成片工程](real-ui-film-engineering.md#声音链路)；访谈解读的铺底跟着口播走，并分频段压低，见 [访谈解读·声音](interview-commentary-direction.md#声音)。数值是起点，按实际口播和铺底调。
- **随场景和章节换声音**，不整片一条。段间用交叉淡化（访谈解读实际用 2.4 秒等功率），章节切换处有节奏变化。
- **开头 5 秒就要有节奏与叙事**（用户 2026-10-20 对电商科普片的要求）：先抛结果或问题，第一拍落在可见的动作上。产品说明片第二版把乐床提到 108 BPM，鼓点在开场之后的第一章进入，开场段没有鼓；这一条是否兑现没有听审，下一版可以把鼓点提前到开场。
- **音效落在情绪点，不是每个动作都响。** 位置感是“先停一下，再落一个声，再说重点”。分三层：情绪落点、转场、轻反馈，轻到有则顺、无则不觉；同一时刻只留一个声。产品界面的音效只跟真实触发，不早于可见因果。
- **密度没有定论。** 用过的有每分钟 8.7 个（访谈解读第二期）、15.9 个（第三期）、约 31 个（产品说明片，33 个事件、63 秒，界面操作多）。三者都没有人耳听过，用户也没有评价过疏密。下一次先听，再按用户反应定，不把任何一个当标准。
- **声音相对口播放置**，整片再统一到目标响度。音效发尖时先换音色、减叠加，再调增益与均衡，不用整体低通糊弄，细则见 [声音与节奏](sound-and-rhythm.md)。

## 从听感反馈到重做

1. **拆成四个维度**：音色、语速、起伏、声音层（配乐与音效）。每个维度选一个可量的代理指标，同时写明它不能代替耳朵。
2. **先量旧版基线**：字/秒（整体与有声段）、音高标准差、能量范围、响度，再定新目标。“快一些”要变成一个具体数字，并记下它的来源。
3. **小样验证手段**：只做一章或几句，对照上面的做法表，已知无效的手段直接跳过。
4. **整稿流程**：分段多取样 → 择优 → 按字级时间戳与能量边缘拼接 → 排程 → 画面按口播重定时 → 混音 → 编码 → 验收。重定时与混音顺序见 [真实界面成片工程](real-ui-film-engineering.md#旁白重做后的时间映射)。
5. **记账**：每次请求登记次数与估算费用，先写预算上限，到顶前停下来问，不悄悄加量。第二版共 226 次请求，约 1.66 元，上限 3 元；按字符计费，报价以当时套餐为准，不沿用旧价。

## 取样与拼接的坑

| 现象 | 处理 |
| --- | --- |
| 取样开头有短促杂音 | 忽略短于 60 ms 的有声段；首个起点取与接口首字时间重叠的有声段 |
| 接口给的末字结束时间偏短（实测最多少 0.25 秒） | 以 5 ms 能量包络确定尾音，不直接按接口时间裁尾 |
| 回听转写把英文单词拆成多个词 | 先合并相邻英文词再比对 |
| 同音字（再／在、地／的、得／的、它／他、她／他、做／作）被算作读错 | 比对前按同音字归一，并单独说明 |
| 个别短分句在所有取样里都被转成同一个错词（实测一句的 6 个取样全中） | 多半是口音加快速语流造成的识别问题，不盲目重抽，列入“请用户重点听”的清单 |
| 回听转写偶尔多出个别字 | 视为不稳定的识别噪声，多取样交叉对照后再判断，不据此淘汰取样 |

## 验收与边界

- 回听转写只证明读对了（没漏字、没加字、数字对），不证明有激情、自然、像本人。语速、音高标准差、能量范围、字准率都是代理指标，只能说“更接近目标”，不能说“听起来更有激情”。
- **激情感、像不像本人、节奏卡点、音效疏密**，没有人耳听过就写 `not_checked`，交付时点名请用户重点听：语速最快的几句、读错风险高的专名和数字、识别反复不稳的短分句、章节转换处。
- 一个人、几部片的反馈不是通用标准。本文的数值是起点；用户给了新偏好，以新偏好为准，并回来改这篇。
- 本人声音只用于授权的本人讲解与作品，不进公开示例、公开 Skill 包或可转发的工程；公开文档和仓库里不放凭证、音色编号、参考录音与声音清单。

来源与实测：2026-10-20 至 11-05 用户多次听片后的反馈；2026-11-05 一条 9:16 产品说明片第二版的实测：整体语速 3.72 → 5.84 字/秒，有声段 4.32 → 6.70，片长 97.9 → 63.0 秒，混音 −14.4 LUFS、响度范围 1.0 LU、真峰值 −3.0 dBFS。这些数字出自仪器与机器识别，没有经过人耳听审。
