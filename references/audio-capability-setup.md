# 音频能力：独立检测与按需安装

供旁白生成、歌词转写、音乐理解／生成、分离人声任务使用。先判断缺的是哪种能力，再进入对应入口；四个入口独立，不要求全部安装，不把它们串成固定流水线。已有可用旁白、可信歌词稿、对齐结果或等效工具时先复用。此页是 Agent 工作指引，不是已运行的检测脚本或本机能力声明。

## 任务路由与官方入口

| 任务需要 | 按需选择 | 安装与使用来源 | 能力边界 |
| --- | --- | --- | --- |
| 从实际演唱取得唱词与时间戳候选 | OpenAI Whisper | [官方 Setup](https://github.com/openai/whisper#setup) | Python 包名为 `openai-whisper`，需要 FFmpeg；歌唱识别和时间戳均须核验，不保证逐字正确 |
| 音乐理解、歌词及音乐信息提取，或用户要求生成／改编音乐 | ACE-Step 1.5 | [官方中文安装指南](https://github.com/ace-step/ACE-Step-1.5/blob/main/docs/zh/INSTALL.md) | 按具体功能检测；音乐理解不等于已取得可靠词级对齐，生成也不是转写原曲的替代品 |
| 伴奏干扰识别，需要尝试分离人声 | Demucs 的 HTDemucs 模型 | [官方仓库及安装说明](https://github.com/facebookresearch/demucs)、[Separating tracks](https://github.com/facebookresearch/demucs#separating-tracks) | 分离人声、鼓、贝斯、其他伴奏；可输出人声＋伴奏，不生成歌词，也不保证 ASR 更准 |
| 产品宣传、知识讲解、资讯、故事、品牌等需要新旁白或参考音色复刻 | Qwen3-TTS Base | [平台选择、容量、模型下载与配音](qwen3-tts-narration.md)；区分 Qwen 官方权重和 MLX 社区转换版 | 参考音频＋对应文本生成新稿件；Base 无预设男女声，音色与语速各自配置；不生成歌曲或替代 ASR |

已有歌只需字幕时，优先检查可信稿和转写能力；需要音乐理解才检查 ACE-Step 对应路径。混音干扰明显或已有识别结果失败时，再评估 HTDemucs，不默认对所有歌曲分离。可比较原混音与分离人声的识别候选，不能因做过分离就跳过校对。

## 共用检测顺序：先静态清点，再短样运行

1. **定位已有环境。** 检查当前项目说明、已知解释器、虚拟环境、项目目录与任务所属进程。记录实际解释器路径和包／项目版本；不同环境各自判断，不因默认 shell 导入失败就认定整机没安装，不全盘扫描或新建重复环境。
2. **不加载模型地清点。** 优先读取包元信息、可执行文件位置、项目配置与模型缓存文件清单。只确认文件、配置和资源，不调用推理、模型加载或启动服务来“探测”。缓存目录存在不代表所选模型完整、兼容或可运行；记录所需权重是否齐全及未知项。不要输出密钥或无关环境变量。
3. **检查任务资源。** 核当前 CPU／GPU 后端、内存、磁盘余量及已有模型／渲染任务的占用；安装前估算环境、所选模型、缓存和产物空间，大小不明先查当前官方说明。重任务串行，复用已有实例；资源不足先缩小验证范围或改用已可用路线。
4. **区分检测与补齐。** 缺依赖、缺权重、版本不兼容、资源不足分别记录。明确已具备条件及需要补齐的具体组件，不把整个产品重新安装作为默认修复。配置中的 API 地址、目录、包或模型存在只证明静态发现。
5. **有条件才短样验证。** 静态条件满足后，用本任务一段包含配音、演唱或识别难点的短片段验证选定功能；长度、模型与后端按任务和资源选择，不默认跑全片或加载最大模型。先核当前版本的加载／缓存行为，确认不会意外联网下载；无法保证时停止加载，转入按需安装判断。检查实际结果后才标该功能 `ready_for_task`，保留版本、输入区间和限制。

## 入口 A：OpenAI Whisper

- **检测项：** 选定 Python 环境及版本、`openai-whisper` 包元信息、FFmpeg 可用性、该环境实际使用的计算后端、所选模型的缓存与完整性。其他 Whisper 实现应按自己的包和文档登记，不能将其安装状态冒充 OpenAI Whisper。
- **缺失时引导：** 提供官方 Setup 链接，列明缺包、FFmpeg 或具体模型。官方 Python 安装包是 `openai-whisper`；安装命令和 Python／后端兼容性按当前官方说明与本机核对，不安装同名无关包，不为了安装覆盖已有全局环境。
- **补齐后验证：** 用实际演唱短样运行转写，检查输出非空、语言及唱词合理、起止时间有序且位于片段内。记录句级／词级的实际精度，检查重复唱句、拖音、漏词和静音幻觉；必要时改模型、上下文或输入路线，保留尝试结果。短样通过只证明该样本可运行，不覆盖全曲准确率。
- **交给下游：** 保存带时间戳的候选稿、方法、音源映射和不确定区间，沿 [字幕导演](subtitle-direction.md) 校对。词级开关或返回字段存在不证明逐字时间可靠，不按字符均摊伪造精度。

## 入口 B：ACE-Step 1.5

- **检测项：** 项目与版本、Python／uv 环境、对应功能入口、所需配置和模型、所选硬件后端及资源。分别记录理解／歌词和音乐信息提取、生成及其他功能的状态；只跑通其中一项不能宣布全部能力可用。
- **缺失时引导：** 提供官方中文安装指南；按其中的 uv 流程及当前系统兼容说明准备项目环境，只下载选定功能需要的模型。首次启动可能自动下载模型，不能用“启动一下”代替只读检测。优先核模型文件和实际加载逻辑，再决定是否启动。
- **补齐后验证：** 理解任务使用短样核返回字段、唱词与音乐信息是否有效，明确哪些值是模型推断；生成任务仅在用户需要音乐生成且已授权的范围内验证。纯检测不得偷偷生成或改写用户音轨。
- **交给下游：** 提取出的歌词仍需校对与独立的时间对齐；BPM、调性等信息不替代逐拍／逐句事件地图。不能将面向生成音乐的歌词时间戳能力直接当成任意已有歌曲的可靠强制对齐器。需要已有歌曲精确字幕时，继续核对当前功能支持范围，缺失则沿可用转写／对齐路线完成。保留用户指定原曲，不为补字幕替换成生成音乐。

## 入口 C：HTDemucs（Demucs 的分离模型）

- **检测项：** 选定环境中的 Demucs、所需音频读取能力与后端兼容性、`htdemucs` 权重缓存及资源。HTDemucs 是模型名，不是让用户另找同名 Python 安装包。权重在缓存中不代表 Demucs 环境已可运行。
- **缺失时引导：** 提供官方仓库的安装与分轨说明；核当前系统、Python／音频依赖的兼容情况及维护状态，再补环境和所选权重，不宣称旧版本可在任意新系统直接使用。分离命令可能下载模型，缺权重时先走安装授权与资源判断。
- **补齐后验证：** 对同一短样分离，核目标人声轨和伴奏轨存在、可解码、时长／采样率／声道合理；实际听审时检查人声漏失、串音和伪影。没有听审时只记录文件与运行验证，不宣称分离质量通过。人声＋伴奏输出不能当作计算量必然更低的承诺。
- **交给下游：** 用人声轨作为可选转写输入，保留原混音候选用于对照；唱词仍以真实原音频为依据。保留片段源偏移，检查分离或预处理是否引入时移，不能直接把短样的零时刻当成原曲零时刻。原曲保持不变；分离轨默认用于分析，不擅自替换成片声音。

## 入口 D：Qwen3-TTS 旁白与参考音色

按 [Qwen 配音接入](qwen3-tts-narration.md) 执行。先静态核对 Python、后端、完整模型（包括 speech_tokenizer）、FFmpeg 与获准参考；已有环境直接复用。缺项时说明所选平台版本、来源、预计容量与资源，由 Agent 在已授权制作／安装范围内完成下载和安装，不止交给用户一个手动安装链接。短样检查文本、自然度、音色和句尾，语速按具体声音校准；实际旁白变更后重新测量字幕与镜头时间。

## 缺失能力的按需安装路径

安装前向用户说明本任务为什么需要该能力、已检测到什么、只需补什么、官方地址、预计下载／磁盘／运行资源及已知限制。沿当前任务授权与宿主规则判断是否可安装；已经明确授权的同一范围不重复确认，超出授权的大下载、收费、外部音频上传或新服务另行处理。用户只询问检测或安装方式时，不自动安装。

具备授权与资源后，由 Agent 仅补齐选定环境、依赖和权重，遵循当前官方／维护者文档，串行执行并保留日志；不要把四个入口捆绑安装，不改全局默认或关闭用户已有任务。完成后回到对应入口做短样验证，再处理必要的全段并进入旁白／歌词校对和编排。

安装失败先读日志，区分下载、环境、后端、模型或资源问题；复用已完成下载和可用环境，不循环重装。提供具体阻塞、受影响任务及可行替代，如已有等效环境、较小模型、可信稿配合可用对齐、资源允许后重试。替代路线的可用性仍须实查；不得未经授权上传音频，也不能因本地缺能力就省略必要歌词和字幕。等待期间可推进不依赖唱词的视觉探索。

## 项目记录与状态

在现有导演笔记／执行记录中保存：所选入口与理由、环境／版本、对应功能、模型及缓存状态、缺项、资源判断、安装授权范围与实际动作、短样输入源区间、输出路径、校对／听审范围、下一步。不要求额外固定文件名或修改 plan.json。

状态区分 `missing`（缺条件）、`detected`（仅静态发现）、`test_failed`（记录具体失败）、`ready_for_task`（选定功能已短样运行）；未验证功能保留未知。运行通过、全段转写完成、歌词已校对、时间已对齐和实际听审分别记录。历史工程产物可以支持“曾运行过”，不能继承为当前环境或当前音频通过。

官方入口及能力边界已在本次任务前序调研核对；这里复用该证据，不声明本轮进行了安装或推理。后续真正执行安装与调用时，仍需核当前版本文档与宿主要求的技术调研。个别机器的目录、权重容量和历史成果不写为所有用户的默认环境。
