# 访谈解读：把外文访谈变成有判断的中文解说

目录：适用与观众所得 · 与相邻类目的分工 · 选题 · 素材与引用边界 · 叙事结构 · 引语与双语字幕 · 解读画面 · 本人判断 · 声音 · 封面 · 验收 · 边界

用户要把一段外文访谈、演讲、播客或发布会解读成中文视频，或复刻“引语 + 卡片 + 本人判断”形式（参考“黄叔精读”）时，选场景 `interview-commentary`，配方 `interview-commentary-explainer`（别名“访谈解读”“超级峰解读”）。本文讲设计与验收；可执行流水线、脚本与已验证参数在 `chaojifeng-interview-commentary`（选题、下载、转写、配音、渲染、封面、验收），模板见 [访谈解读模板](../templates/interview-commentary.md)。

## 适用与观众所得

观众看完能复述 3 个关键判断，知道它们对自己所处的环境意味着什么，并带走一个可以马上对照自己的问题。价值来自两件事：选对题，用解读者自己的认知给出判断。特效只服务于把判断讲清楚。

## 与相邻类目的分工

| 类目 | 主体 | 区别 |
| --- | --- | --- |
| knowledge-explainer | 概念、机制 | 解说的主体是“别人的原话 + 解读者的判断”，证据是引语与出处，不是自建的模型 |
| news-brief | 事件、来源、日期、未知 | 解说沿用来源与日期的核验，再加一层本人判断，必须分清原话、转述与判断 |
| product-promo | 产品价值 | 解说不推销产品，对外的结论是观众自己的下一步 |

## 选题

- 先查人物与节目，再查主题。窄关键词多命中小频道，人物和播客关键词才出现大体量访谈。
- 相关性是门槛：必须落到目标受众的真实问题，并能和解读者已有的认知对话；对不上的热门题不做。
- 在相关的前提下再看权威（人物与发布方）、热度（同一来源口径内比较）、时效（易变内容提高权重）、素材可得性（画质、原声、有无硬字幕）。播放量等数据写明截止日期。
- 选题卡记录入围对比与落选原因，落选的留作备选。

## 素材与引用边界

- 素材是公开视频，下载到本地做评论依据，不再分发原片，不上传原片。
- 引语总量不超过原片的三分之一，单段 5 到 30 秒。第一期 7 段共 99 秒，占原片 23%，占成片 30%。
- 每段引语后面都有解读，不连放两段引语。保留否定、条件与语境，译文不扩大原话，不剪出相反的意思。
- 取说话人的原声音轨，不要自动配音轨。
- 右上角标注来源，格式“频道名 访谈 · 年.月”，不带“素材 · ”前缀（第一、二期带过，用户 2026-11-05 要求去掉）。它是事实标注，不是制作自述。
- 引语取自视频最后几十秒时，画面会带平台片尾版式（小窗加推荐位）。抽帧确认，有就提前结束片段、裁切，或用整屏图表盖住，原声继续。

## 叙事结构

| 段落 | 观众所得 | 第一期时长 | 画面与声音 |
| --- | --- | --- | --- |
| 冷开场 | 先听到最有冲突的一句原话 | 12.5 秒 | 素材片段，原声，双语字幕，人物条短暂出现 |
| 揭示人物 | 知道这句话是谁说的、凭什么 | 8.9 秒 | 人物静帧缓推，名字卡，头衔逐项出现 |
| 来源卡（默认不做） | 知道出处、长度、日期、热度 | 第一至三期有，6.1 秒；v3.2 起删去 | 用户 2026-11-05 看过成片后明确要求“不需要显示这个片段，没必要介绍这个，直接进入主题”，出处只由右上角的出处角标署名；用户点名要时，才做缩略图、频道、标题与数据，数据注明截止日期 |
| 路线图 | 知道听什么、为谁听 | 25.5 秒 | 步骤卡，当前项高亮，面向对象标签 |
| 三段主体 | 每段拿走一个判断 | 约 256 秒 | 引语 → 解读画面（第三期起以图表为主）→ 本人判断，循环三次 |
| 收尾 | 带走自检问题 | 22.4 秒 | 对照面板，老板与求职者各一个问题，随后是品牌落款；屏幕上不放评论邀请与行动号召（第一、二期的收尾卡带评论邀请，用户 2026-11-05 要求不放到屏幕上） |

整片 5 到 8 分钟。第一期 25 个画面、45 句口播，成片 5 分 31 秒。结构按职责使用，没有新内容的段落不保留。

收尾可以用一段固定的品牌落款：为“超级峰解读”做的一段 6 秒、科技感的结尾，能在每一期复用（山峰波形加字标，带落款音效与铺底，16:9 与 9:16 各一条）。落款只做品牌收束，不替代自检问题；做法与成品位置见 `chaojifeng-interview-commentary/references/visual-scenes.md` 的“片尾与落款”。

## 引语与双语字幕

- 字幕在底部居中，**中文为主、英文为辅**，英文紧贴对应中文下方，成组出现、成组消失。
- 引语的英文是净化后的原话：去掉口吃、重复和语气词，保留词序、数字、否定和条件。中文是口语化译文，每条建议不超过 22 个汉字，英文不超过 80 个字符。
- 口播字幕按短语切分，比语音早出现约 0.05 秒；末句多停 0.30 秒，其余 0.55 秒，间隙短于 0.35 秒时连续显示。
- 英文行不使用破折号、冒号与分号；中文遵守创作风格。
- 每条字幕（中文、英文、原片字幕）句末不带标点，句中标点保留（用户 2026-11-05 要求去掉 `，。` 这类标点）。在生成时间线时统一剥掉，再按成片里实际烧录的字幕逐条核查。

## 解读画面

**默认用图表与图形，少用文字卡**（用户 2026-11-05 的反馈：“尽量减少 B Roll 的卡片方式的呈现样式，并且加入更多图表、更具象的形式，比如，可视化的要素让整体画面更具有说服力”）。先问“这句话在讲哪种关系”，再选图形，每个画面一种关系，同一时刻只出现一个，每个画面只加一个新负荷。元素用“句内短语引用”定时，口播改动后自动跟随。

| 这句话在讲 | 用什么图形 |
| --- | --- |
| 一个传言或一个大数字 | 圆环从 0 涨到目标值，随后划掉并换成一句否定 |
| 数量的积累 | 时间线上编号方块逐格点亮，右边大数字计数 |
| 一个岗位由若干任务组成，机器接走一部分 | 环形任务图，两种颜色分出“机器接得走”和“留在人手里” |
| 前提不满足，所以接不进来 | 几个前提用虚线接向芯片，接不上，打叉，再换成一排人 |
| 两种角色互相靠近 | 两个圆重叠，各带箭头 |
| 工作范围变宽 | 雷达图，从一项能力长成多项 |
| 越……越……的关联、供需的差距 | 趋势曲线，差距用双曲线加缺口；只画走向，不标虚构刻度 |
| 同等条件下的取舍 | 天平，一端加上筹码后倾斜；招聘取舍也可用简历行打叉打勾 |
| 两个要素相加得出结果 | 等式，每个要素带图标 |
| 并列的几类对象，汇成一个结论 | 并列项经漏斗汇成一句总结，再接因果步骤 |
| 做法的三步、路线与章节 | 三步连线图、路线图与进度条、章节页，当前项高亮 |
| 谁说的、凭什么 | 人物锁定框加履历连线 |
| 出处与数据 | 视频页面式来源条，观看数滚动，注明截止日期 |

规则：数字、占比、日期只写有出处的事实；对外画面不写“示意”“演示”之类的制作说明；原声继续、需要图解的时段可以用整屏图表盖住访谈画面。本项目自定的验收线（不是对标视频的数值）：图形占全片 ≥ 40%，连续的纯访谈画面 ≤ 20 秒；第三期（v3）实测 77.1% 与 13.96 秒。24 种场景、字段与做法见 `chaojifeng-interview-commentary/references/visual-scenes.md`。

下面是第一、二期用的文字卡片对照，按这句话的逻辑结构选卡，v3 里只在没有合适图形时兜底：

| 这句话在讲 | 用什么卡片 |
| --- | --- |
| 人物与头衔 | 名字卡，头衔逐项出现 |
| 出处与数据（用户点名要时） | 来源卡；默认不做，出处用右上角角标署名 |
| 路线、步骤、三个问题 | 步骤卡，当前项高亮，其余变暗 |
| 一个岗位由若干任务组成，机器接走一部分 | 任务分流卡，左列打勾，右列标橙 |
| 并列的几类概念，加一句括号总结 | 并列方块加括号 |
| 一个概念展开成多个 | 展开卡 |
| 两个对象各自的视角 | 双行视角卡 |
| 一个事实推出另一个 | 事实推论卡，后者橙色 |
| 两个要素相加 | 加法卡 |
| 数量对比或变化 | 数字跳动卡 |
| 三步流程 | 流程卡 |
| 一句金句 | 大字金句，关键词橙色 |
| 一句大话加几条并列要点 | 大句加并列标签 |
| 收尾自检 | 收尾卡（旧：带评论邀请；现：对照面板加品牌落款，不放评论邀请） |

## 本人判断

- 第一人称事实和判断先登记，再写进稿子。证据等级分三档：本人确认的经历（可写）、本人的判断或假设（只能写成“我的判断”）、整理者推断（不写）。
- 时间敏感事实带口径，例如“到今年 6 月累计做过 18 款产品”，不写“目前”。
- 没有证据的经历、客户案例和业绩数字不写；知识库没有采用数据，就只写判断。
- 判断与原话对话：一致、补充或不同意都可以，不为了顺口扭曲原话，也不附和。
- 收尾给不同受众各一个自检问题，问题今天就能对照自己回答。
- 配方带 `knowledge.truth-ledger` 等表达。计划选了 `knowledge.*` 表达就写 `plan.knowledge`，事实登记即真相账本，每条事实写明来源与日期，没查到的写进 `unknown`，再运行 `validate_plan.py`。它只核结构与引用，不证明原话被理解对、判断成立或观众看懂。字段见 [知识包合同](knowledge-pack.md)。

## 声音

- 引语保留说话人原声，口播与引语分时段，不叠。素材原声先归一到相近响度，再整体定到目标响度，限幅后留出真峰值余量。第一期实测 −16.0 LUFS、真峰值 −1.4 dBFS，这是实测值，不是通用目标。
- 旁白用授权的本人音色。默认本机 Qwen3-TTS；用户明确指定用 API 时，可以用平台上已有的克隆音色（第二期用火山声音复刻，口播文字会发给服务商，要说明服务与费用，不新建音色槽位）。回听转写只证明读对了、没有漏字加字，不证明像不像本人、自然不自然。没有人耳听过就保持 `not_checked`，不写“音色已还原”。
- 说话人嵌入的相似度分数区分度低（第一期里别人的原声也有 0.95），长时平均频谱距离同理，都不当作像本人的证据。
- 本人音色与参考录音只用于授权的本人讲解，不进入公开示例或可转发的工程。
- **背景声音与音效**（第二期起）：口播和访谈原声永远是主角，再加一条很轻的背景声音和少量落在情绪点上的音效。
  - 音效学对标的位置感：先停一下，再落一个声，再说重点，不是每个动作都配声。分三层：情绪落点（人名揭示、我的判断、数字落定、行动提示、落款）、转场（切进原声）、轻反馈（卡片出现、条目出现，轻到有则顺、无则不觉）。第二期当时定的口径是每分钟约 9 个以内（实际 8.7 个）；第三期图表画面多出轻反馈，实测每分钟 15.9 个（落点加转场 6.6 个，轻反馈 9.2 个），没有人耳听过，不知道偏不偏密，口径先不改，下一期先听再定。同一时刻只留一个，访谈原声内部原则上不加声。
  - 背景声音宁可轻：选器乐、起音稀疏、没有人声节奏的，口播下约低 18 dB，停顿处略升，口播响起时压低，访谈段再低。对标视频在部分硬切处是数字静音，没有贯穿的音乐床，所以这一层是增量，不是照搬。
  - 声音相对口播放置，不看绝对值，整片再统一到目标响度。第二期的素材来自本机剪映素材库缓存，只读，商用许可要单独核实，没核实就不宣称可商用；第三期起主路线换成下一条的 ACE，剪映缓存只作兜底。
  - **第三期起默认用本机 ACE-Step 1.5 生成铺底与音效**（用户 2026-11-05 指定，并要求不同场景用不同的声音、铺底不能影响讲话）：离线、串行、可断点续跑。全片 5 段铺底按章节更换，段间 2.4 秒等功率交叉淡化；铺底响度跟着口播走（比口播低 18.5 LU），再经三频段压低（口播出现时低、中、高频分别压 4、7、9 dB，中频最深，人声在那里），音效按与人声的电平差自动减弱。ACE 生成的噪声类音效（风、扫、嘶声）带约 31 Hz 的调幅与隆隆声，扫音改用合成噪声扫频，必要时与 ACE 的音色层叠，要披露成“ACE 与信号合成的混合”，不写成全部由 ACE 生成。铺底与音效按指标筛选，不凭听感。ACE-Step 1.5 的代码是 MIT，厂方称生成内容可商用，我没有逐项核对，发布前单列为 `needs_check`。参数、选材与脚本见 `chaojifeng-interview-commentary/references/sound-ace.md`。
  - 验收：对只含音效的分轨审计起音时刻（ok 只说明时刻对得上，不说明好听），再核对电平关系、访谈段内无音效（有例外就逐条写明）和含声音后的口播清晰度；铺底是否压住口播用“铺底与人声的遮蔽比”衡量：只统计人声有声的帧，看 300 Hz 到 3 kHz 里铺底比人声低多少 dB，第三期均值 −30.2 dB，p90 −21.4 dB。它与回听转写一样只是代理指标，没有人耳听过就写 `not_checked`。做法、参数与脚本见 `chaojifeng-interview-commentary/references/sound-design.md`（第二期，剪映缓存）与 `sound-ace.md`（第三期，ACE）。

## 封面

做 3:4、4:3、16:9 三种。访谈类封面必须包含被访谈者本人，从视频切帧作图生图参考，请求里写明参考图只用于保持长相，不要出现原片台标与水印。文字逐字列出并实际看图核对。后两个画幅用前一个封面当风格参考，成套感更好；尺寸不符时从原图派生，不为尺寸重新生图。

## 验收

| 项 | 要看什么 |
| --- | --- |
| 事实 | 人名、头衔、日期、数据口径与来源一致；引语逐字对照原话 |
| 判断 | 每条第一人称事实有证据等级；没有编造的经历与案例 |
| 对外文本 | 创作风格审计硬性命中清零，再通读制作自述与翻案句式；按成片里实际烧录的字幕逐条核对句末标点、制作身份标签与“素材 · ”前缀 |
| 画面 | 每个画面抽帧看字数、换行、遮挡、人脸位置、过渡；图形占比与最长纯访谈段（本项目自定的验收线 ≥ 40%、≤ 20 秒）；整片的叠层是否都在位（叠层帧里混了不带透明通道的整屏图，ffmpeg 曾静默丢掉后面的长叠层，用 `qa_overlay_present.py` 逐段核对） |
| 声音 | 口播逐字回听、引语字幕召回、响度与真峰值；有背景声音与音效时，加音效起音审计、电平关系、访谈段内无音效、铺底与人声的遮蔽比；听感单列 |
| 时间 | 每句配音能量起点对齐字幕起点，不凭 ASR 首字时间判断 |
| 封面 | 逐字核对，人物像参考帧，无台标 |
| 登记 | 设计、预览、导出、听审、观众理解分别记录 |

## 边界

- 一期成片只证明这一期、这个版本和实际检查范围，不外推为整类验证。观众理解没有做过测试，保持 `not_run`。
- 听感没有听审时，不写“自然”“像本人”“有感染力”。
- 素材、参考音色与知识库私有内容不进入公开分发的 Skill 与示例；背景声音与音效素材的授权状态单独记录。
- 第三期（v3）的图表优先、ACE 声音与品牌落款，是按用户 2026-11-05 的反馈做的，当时用户还没有看过成片。其中具体的选择（图形怎么画、事件密度、铺底的选法、验收线的数值）只经过工具检查，没有经过用户验收和人耳听审，用的时候当作可调整的起点，不当作已被验证的标准。
