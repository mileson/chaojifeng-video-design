# 音乐镜头与运动编排

用于歌曲或音乐主导画面的 `music-visual`、音乐表演和需要音乐推进的相关场景；先读 [歌曲视觉导演](song-visual-direction.md)。音乐驱动画面节奏并营造氛围，画面的场景、动作、运镜、转场与动效建立吸引力和沉浸感。慢歌同样需要卡点与运动编排：唱句起落、旋律转折、拖音、呼吸、停顿和乐器进入都可成为视觉锚点；快慢改变速度、幅度与密度，不降低表达要求。不规定固定镜头数、风格或人物故事；用户明确指定静态、长镜、表现方式或原声时优先，静态作品仍设计与其约束兼容的音乐关系。

## 一、音乐事件地图

先按 [声画事件模型](music-event-model.md) 区分段落、乐句、瞬间三层锚点；分别支持整体关系变化、动作过程与关键落点。歌词时间线与音乐地图共同支持剧本，不把一句歌词等同一个镜头，也不让整片只响应音量。

核真实音源、版本、长度和所用区间；在可用条件下回听，以源时间标出乐段、唱句、旋律走势、重音、节拍、停顿与释放。唱词存在时核实际唱词及对应区间，纯音乐不编歌词。每个锚点记录时间／范围、类别、依据和状态：实际听审或人工标记、信号测量的候选、估计／未知；信号起音、频率与RMS不自动等于拍点、乐句边界、情绪高潮或已听审。变速或速度不稳时沿真实锚点，不凭单个BPM生成全曲拍网。

记录原音源时间到整片绝对时间的映射，引用已有 `music-cue-sheet.json` 和计划beat；换曲、片段、速率、帧率后重建受影响锚点。无法听审或识别时仍可用候选做有限设计，明确估计与未验证范围；不能编出精确唱词、卡点或声画通过状态。用户指定歌曲与原声约束优先，增加音效需有明确职责，不能为了卡点遮盖歌声或擅自改曲。

## 二、把乐句写成镜头事件

有演唱时先取得 [歌词时间线](subtitle-direction.md)，连同音乐事件地图作为编排依据；用 [编排模板](../templates/music-direction.md) 或已有项目计划记录下列判断。只给出形容词、场景名称或效果名称不算完成镜头编排。

对重要乐句、转折或声音动机，在现有计划或项目导演笔记写声画事件卡；按片复杂度增减，不强制每拍、每句一行，不新造必填JSON字段。使用同一张卡完成设计与复验：

| 项目 | 问题 |
| --- | --- |
| 声音锚点 | 段落／乐句／瞬间、源区间及成片时刻；听审、测量候选或估计 |
| 情绪目的 | 这一事件希望改变什么感受，为什么适合当前曲段 |
| 事件前后变化 | 主体、行动、关系的前态→变化→后态；环境循环不能独自证明推进 |
| 视线与运镜 | 先看哪里→什么引导→最后发现什么；景别、视差、遮挡、焦点或跟随怎样兑现 |
| 动作峰值 | 准备、积累、抵达／接触／揭示、回落与后果；哪个阶段对应哪个声音，偏移及理由 |
| 下镜联系 | 下一镜通过视线、方向、主体、形状、遮挡、声音或语义怎样接住 |
| 实际验证 | 预期变化、实际产物版本和连续看听区间、观察、缺口及复验；没有看听不得填通过 |

资产、工具职责与显著效果的附着层、遮挡和驱动关系写在卡的实现备注，细则见 [材质与空间](music-event-model.md#5-材质与空间让效果属于场景)。模板未填完不能靠堆效果补齐，卡填完也不代表已实现。

一次改变可以是动作、镜头、关系或音乐的组合；不要每拍都切镜、闪光或做同样转场。长镜仍需设计可辨的焦点、主体、构图、动作或关系变化，并说明为何比切镜适合此曲；用户明确要求音乐律动、运镜或镜头切换时，不能以静态构图、雨粒或整体亮度变化替代所要求的表达。确需静止作为对比、停顿或留白时说明其音乐和情绪作用。

将事件映射到已有 `scene.intent`、`director.beats`、`scene.beats`、`motions`、`audio_cues` 及项目笔记；整片与音源时钟分开，音乐驱动三维已有 `score.json` 为有效事件输入时继续复用，不维护互相竞争的第二套时间轴。计划通过只证明结构，不证明镜头已经发生或卡点好听。

## 三、设计运动与镜头接力

为每个关键事件确定一个可辨主运动，再按需要协调次运动和环境。主运动可由角色、物件、形态、画面焦点或镜头承担，不强迫所有层同时运动。先写前态→预备→变化→接触／峰值→落定→余势／停留；各阶段可省略，但动作和拍点的对应要能说清。次运动、材质或背景可以先后错开，也可共同发力；变形、弹性、弧线、速度和运动幅度按材质、情绪、尺度与参考选择，静止也是选择。

乐句之间根据语义选直接切换、匹配动作／形状、遮挡揭示、方向延续、声音接桥或长镜内视角变化；转场说明揭示了什么，不叠效果掩盖内容。用同一意象在不同状态中发展：重复时改变关系、尺度、位置或含义，避免仅更换背景或亮度。切点可落在拍点、唱句、呼吸或反差处，也可有意提前／延后；不套统一间隔、固定一帧偏移、示例BPM或弹性参数。

选实际能兑现主运动的资产和执行路线：已有素材／授权资产、绘制、二维、三维或混合均可。Remotion、HyperFrames、Anime.js 等是职责不同的候选，不因工具名或库数量保证叙事、同步或效果；未探测能力保持未知。优先复用环境，重任务串行，避免先完整高规格渲染再发现主线无变化。

## 四、代码构建可动场景

音乐视频默认以代码构建可动画、可编辑的场景和主体，让画面与音乐事件一起变化。代码负责对象状态、动作、镜头、合成、字幕和转场的组织；二维、2.5D、三维或混合皆可，根据可用能力和本片需要选择。生成图片、摄影或其他素材可作背景、纹理、贴纸、装饰与局部资产；为叙事服务的素材仍可使用，但不能以单张整图的缩放、平移或淡入淡出充当默认成片。用户明确指定静态图片作品、特定素材或其他表现方式时，以用户约束为准。

在已有导演笔记或事件卡中按需列出可独立控制的主体、前景／中景／背景、镜头、字幕及转场，说明对象行为与前后状态、空间或遮挡关系、运动由哪个音乐锚点驱动、对应实现位置及缺口。不同层按事件需要独立或协同运动，不要求每层持续运动；可用停顿、留白与长镜，但需有明确的音乐和叙事作用。真实可见变化优先于代码层数、素材数量和引擎名称。

开场与重要乐句至少安排与本片声音锚点有关的可辨事件及其前后关系：可以是主体行为、层间视差与揭示、镜头运动或切换、动作衔接／遮挡转场、文字语义动作等有目的的组合。不是要求每个片段都使用全部手段，也不设固定镜头数；避免单张图推拉加循环粒子、只换亮度、字幕一律淡入淡出，替代已要求的动作、切换、转场或文字动效。动作峰值或切点的时间及依据写入现有排程；句级锚点、信号候选和听审确认分别标记，候选不能冒充精准卡点。

## 五、制作路线由镜头需求决定

将重要镜头的资产、主动作、相机、合成和字幕职责分配到实际可用的执行路线，并标明实现位置、缺口与替代方案。以下是本库已有路线的选用起点，不是必装清单或工具效果承诺；具体接口需按宿主要求核文档，能力未探测不得标 ready。

| 画面需要 | 可选职责分配 | 预演时必须看到 |
| --- | --- | --- |
| 物件表演、真实空间、材质和摄影机调度 | Blender 制作场景／动作／相机，现有合成器或 Remotion 组织画面与字幕 | 主体动作、空间变化与机位揭示真实发生，不能只交单帧场景 |
| 程序化形态、几何与音乐事件响应 | Three.js 实现场景状态与相机，沿已有工程接入统一排程 | 事件有前后状态，运动峰值受音乐锚点控制，不能只增加粒子密度 |
| 剪辑节奏、二维动效、动态图文与双语歌词 | Remotion 或已有同等执行器承担时序、合成与文字动作 | 切换、转场、重点词和阅读窗实际出现在导出中 |
| 具体人物行为或复杂实体表演 | 复用适配影像、授权素材或可用生成能力，再剪辑合成 | 主体身份、行为后果、空间与跨镜接力成立 |

可用一个引擎完成时不强制混用；必须混合时共用音源映射与事件排程。不能因选择了工具就认为叙事已解决，也不能因实现困难静默删掉关键动作、场景或字幕。先尝试能保留同一表达目的的替代资产／动作，再明确仍未解决的缺口。

## 六、内部短段与成片审片

歌词或旁白字幕与镜头、音乐一起编排，按 [字幕导演与配色](subtitle-direction.md) 决定双语层级、唱句落点、重点词和适合乐段的动效；字幕必须实际出现并可读，不以动效或卡点挤占阅读窗。

正式渲染全片前，低成本制作或复用可播放短段，覆盖前三秒及至少一个关键音乐锚点和相邻镜头接力；必要时合并为同一短段，播放连续动作，先定位最大表达问题，再局部调整。检查主体是否真的变、镜头与落点是否可辨、字幕成组动效及转场是否真实发生、接缝及前后状态是否成立。若预期动作／运镜／转场／字幕动效未兑现，先调整场景结构、实现路线或动画并复验，不因渲染成功放行；无法兑现时交候选并写明具体能力或资源阻塞。direct 模式在同轮内部完成检查与返修，不要求用户先审样；用户明确 staged 时按其节点等待。只有静帧时能检查构图和状态，不能声称连续运动或卡点通过。

预演先覆盖开场和首个关键声音落点，再按风险补代表性转折、材质和转场；能够合在同一短段就复用，不强制多次渲染。看片前先写预期事件，正常尺寸、正常速度连续看后独立描述实际变化，再对照事件卡。只在暂停、放大或查看参数时能察觉的变化，不能直接当作所要求的明显运镜或冲击力。慢歌也核对蓄势、峰值、落定与余韵是否由真实音乐带动，不能只核动画开始时刻。

| 检查 | 需要留下的证据或返修方向 |
| --- | --- |
| 开场与承接 | 首帧焦点、前三秒实际事件、声音入口和后续承接；空等、只显标题而无预期表达时重排 |
| 场景与意象发展 | 关键事件前后发生了什么，具体行为／关系或抽象形态怎样发展；仅换滤镜、雨量、亮度不能证明发展 |
| 镜头与动效层次 | 景别／空间／焦点／主体动作如何随乐段变化；检查运动速度、幅度、切换密度与高潮是否有意区分 |
| 声画落点 | 逐个记录重要锚点的源时刻、映射后计划时刻、实际动作峰值／切点及证据；偏移按本段意图判断，不套统一容差 |
| 转场接力 | 看切点前后连续画面，核方向、动作、形状或语义如何接住，遮挡转场不能掩盖内容缺失 |
| 材质与空间 | 核显著效果的空间层、附着、运动、遮挡和光影是否一致；失败优先调整资产或路线，不重复叠装饰 |
| 歌词与字幕 | 有演唱时核实际时间稿、识别／校对状态、双语呈现、强调和阅读；用户明确无字幕的按其要求 |

上述是制作与审片要求，现有结构校验器不会自动验证导演判断。填写完成的表格不能替代实现；缺少听审／观看能力时保留对应未验证状态，不能凭音乐地图和计划通过判定沉浸感成立。

结合真实音轨看关键短段和最终成片，核音乐锚点与动作实际落点、唱句／字幕、镜头节奏、音乐主次与结尾。遮住字幕或静音可辅助检查画面主线，但不能替代声画一起播放。按用户要求逐项标记：视觉叙事、动作／运镜／切换、声画同步、完整播放、实际听审、观众反馈分别写证据和范围。只有机器测量、素材存在、计划通过或抽帧时，不能升级为听感／共鸣通过；没有听审能力标 partial/not_run，写明限制。已知必要要求未兑现先返修；资源或能力不足时交候选及缺口，不虚称完成。
