# 审片与局部修改

使用 [执行合同](execution-contract.md) 时，将 compile／audit／impact 报告加入现有 delivery 的相关 evidence。核必要动作的实现与观测、重复定位一致性，以及双语组在运动和切换时是否保持英文紧贴中文下方。自动报告只覆盖提供的帧与状态；仍需看首段、运动极值、切口和连续片段，并听审音乐落点。状态变化不证明运镜可辨，文字框相邻不证明可读。返修后重新编译并更新观测与看听范围。

| 维度 | 检查内容 | 边界 |
| --- | --- | --- |
| structure | ID、引用、时间、素材、能力、计划/产物一致 | 自动检查不核知识或审美 |
| semantic | 来源、单位、因果/分支、功能与画面对应 | 用独立原始材料，不以同一错误提取自证 |
| visual | 长中文、裁切、对比度、层级、遮挡、字幕安全区 | 实际查看；填满像素不代表有效信息 |
| playback | 完整时长、连续播放、黑闪帧、转场/错位 | 属性、抽样与完整播放分开 |
| audio | 音轨、峰值、清晰、落点、起结尾 | 实际试听；声明/哈希不保证听感 |
| comprehension | 观众能否正确解释/执行 | 真实反馈/实验；没做则not_run |

passed写观察或证据路径。设计示意、源码存在、预览、导出分别记录。图上字可能通过几何校验却不可读；背景SVG会抬高密度；静止可能是合理阅读，大帧差也可能无意义。

实际看首帧、最密帧、关系落定、图上文字、运动极值、进退场与转场。联系表/密集条带用于定位，再看原尺寸与连续视频。没看/没听不标通过。覆盖长标题、图片比例、深色底文字、字体语言变化。逐镜核观众所得、焦点、变换含义、文案/旁白冲突与停留。估时公式不是全部观众标准。

## 默认触发与必要要求未通过时的交付

信息流科普／宣传自动核首帧与前三秒：首个有效信息、首句人声、画面兑现和正文承接分别记实际范围，不让无内容前奏或品牌等待占据开头。事实画面核是否实际检索原始素材、缺口与生成边界；有歌词逐句核事实、真实唱词、字幕、主动作及乐句接力。只读过规则或写了分镜不算已经执行。

有字幕时按 [字幕导演与配色](subtitle-direction.md) 核成片实际字幕覆盖、语言和翻译、唱句时间、重点词、完整阅读窗、字幕安全区、背景变化及主体遮挡。音乐字幕还需核可辨动效与声音的关系；没有实际听审不声称同步通过。字幕缺失、错词或明显错位先返修，受限时说明具体缺口。

已知核心词漏唱、事实错误、明显字幕错位、与任务不符的长等待、必要声音缺失或用户已否定的接缝仍未解决时，继续定位和返修；无法完成则交代具体阻塞，版本明确为候选／未通过。导出成功、自动分数高或如实披露缺陷都不能把必要要求改成已完成。技术检查、导演自检、完整观看、实际听审和用户接受分别记录，不用一个总通过数覆盖失败项。

换音轨后重置歌词覆盖、字幕／动作／音效同步及声音检查；保留旧版记录而不继承接受状态。词音、声线、节奏／旋律、混音与接缝分开验收；没有听审能力时audio保持partial/not_run并列待听区间，不能宣称声音达标，也不因此默认设置逐片试片确认门禁。

使用资产库／HDRI／日语旁白时，沿 [制作工具合同](production-tool-contract.md) 核角色与动作适配、来源与许可、计划及文件哈希，查同镜头光照／反射基线与候选、实际静帧／片段范围和成本。`production_tools.py check --require-reviewed`只拒绝已登记但未完成的灯光／听审声明，不代替看像素、听声音或全片检查；API可查、MCP可连、导入成功与视觉改善分别验收。语音拼接和ASR命中不证明句间连续性或音色合格。

使用 [动态标注](visual-emphasis.md) 时，还需核完整操作单元、标签语义、步骤/互斥编号、文字保护、引线归属、裁切重基准和运动中的跟随。按实际观看尺寸查看完整镜头、局部、关键时刻联系表及连续片段；尤其检查标注出现/退出、相机极值、字幕切换和目标离屏。独立几何检查只记录采样范围，最多awaiting_visual_review；不能继承截图或旧版成片的通过结论。

## 导演审片的六个问题

在项目内保留简短审片记录：每项写所看／所听范围、问题时间点、理由和修改结果。可在原 delivery.checks 的 evidence 指向同一记录，不必改造旧交付合同。

| 维度 | 判断与失败信号 | 对应交付检查 |
| --- | --- | --- |
| 声音 | 主次清楚、动作因果、尾音与起止自然；不能只检音轨存在 | audio |
| 画面 | 主体、空间、文字、连续性明确；生成异常按内容边界处理 | visual、playback |
| 审美 | 字体、色彩、材质、光线、运动气质与品牌一致；说明判断理由 | visual |
| 节奏 | 建立、推进、重音、阅读和释放成立；快与响不等于有节奏 | playback、audio |
| 叙事 | 每镜有信息／感受变化，元素使命与贯穿线可追；没有观众测试不称理解通过 | semantic、comprehension |
| 科技感 | 精确响应、结构、材质与声音服务本内容；装饰不能遮住证据 | visual、semantic、audio |

品牌片检查愿景与事实边界、母题一致与情绪走向；音乐片检查段落、变奏、声画关联和接缝，不强加人物故事。静音／隐藏文字／随机seek只在适用时作诊断，不能统一规定所有片型必须通过。评审者的审美判断与首次观众复述分开；不以导演意图自证观众感受。

音乐主导画面按 [音乐镜头与运动编排](music-shot-choreography.md) 对照用户要求与实际短段／整片，分别核音乐锚点证据、主体前后变化、镜头与动作落点、跨镜接力、听审和观众反馈。明确要求卡点、运镜、镜头切换或动效时，不以光影、背景粒子和计划中分段数量代替实际可辨的表达；长镜也要检查内部变化是否支撑意图。无法实际听审就标 partial/not_run，不能由声波、抽帧或时间一致推断听感通过。

音乐片默认追加以下核对：有演唱是否取得实际歌词时间稿，缺失时是否尝试可用 ASR／对齐并记录阻塞；场景与意象是否通过行为、空间或形态变化推进；信息流开场首帧及前三秒是否有可辨事件和后续承接；慢歌的唱句、旋律、呼吸与停顿是否带动运动蓄势、峰值、落定和切换；字幕、工具承诺的主动作与关键转场是否在实际导出中兑现。按 [编排模板](../templates/music-direction.md) 逐项对照意图与结果，单列失败和未验证项，不能因成片可播放而跳过。没有观众或平台数据不把导演自检写成感染力、留存或爆款已验证。

沿 [声画事件模型的感知验收](music-event-model.md#6-感知验收预期与实际分开) 回填同一事件卡：先在正常尺寸、正常速度下独立描述实际看到的主体、变化和后果，再对照预期。用临时隐藏字幕诊断视觉主线，声画连续回放核峰值和切点，相邻段落比较核发展；歌词型作品保留文字的本来职责。显著雨水、反射、阴影或粒子需核空间层、附着、遮挡和驱动的一致性。仅有 camera／scale 参数变化、循环环境效果、已填卡或计划中分段，不能判定用户所要求的明显运镜、冲击或律动通过；“匹配这首歌”、同步、感动与停留分别记录，缺少证据的保留未验证。发现表达不足时优先调整事件、注意力、动作幅度或实现路线，并按受影响区间复验。

修改时定位scene/element/beat/narration ID，先读计划与实现，列影响范围再执行。别不必要地重生成整片或要求用户手改。

| 改动 | 重验依赖 |
| --- | --- |
| 色/字/布局 | 品牌、字宽、对比度、遮挡、对应帧与产物 |
| 标题/正文 | 事实、容量、停留、字幕及相关镜头 |
| 旁白/音色/语速 | 实测时长、字幕、marks、后续时间、cue/混音 |
| 动效/相机/转场 | 属性冲突、裁切、前后状态、时钟/边界 |
| 框选/标签/引线 | 源到屏幕映射、完整目标、文字/字幕保护、进退场、编号语义与实际显示字号 |
| 数据/产品功能 | 原始证据、尺度单位、真实状态与主张 |
| 素材或生成内容 | 来源、主体一致、文件哈希和使用镜头 |
| 主线／角色使命／揭示顺序 | 故事节拍、前后镜头、身份、视角、声音接桥与观众所得 |
| 音乐段落／节奏／能量 | 动作落点、阅读窗、旁白清晰、混音、尾音与循环接缝 |

保存revision与变更ID。影响视频字节后重新导出并更新哈希；局部预览只验对应范围。无可靠局部渲染可整片重渲，但只改必要源。某引擎旧音轨拦截不能泛化所有分支。

失败先看日志和运行态，分素材、计划、执行器、字体、编码、模型或策略。保留源和错误，修可修部分；不能安全推进则报实际产物与阻塞。降装饰、拆镜、延时、静态表达可以选择，但不静默删必需内容或声音。

## 产品证据与对照审片

逐章节核主张与可读证据，分清输入、中间态、结果和示意；分别查running/success/partial/failure，不让同一成功动效覆盖所有状态。内外时钟按实际素材区间核对，父层时长、子动画末尾和声音尾音单独检查。固定舞台缩小证据时应换近景，长中文替换后重验几何。

前后对照记录固定条件及唯一变化层；不同片段的重放不当严格A/B，响度不同单列。实际看/听之后再评价清晰、审美和疲劳。修改媒体起点、速率或镜头时长时，重验相关标注、声画锚点、尾音及下游时间。随机seek只在支持的执行器上做，其他沿顺序播放/受控录屏验证。

## 发布片的测量审片与参考片研究

成片后用 `film_probe.py` 取镜头切点、各段占比、响度与真峰值、能量谷和调色板，把切点与计划里的场景起点逐一对照；它只说明“出现了什么”，看和听另记。音效用 `audio_event_audit.py` 对不含音乐的音效分轨核对：`schedule_drift` 先从事件表重新生成排程，`late` 或 `early` 查 `onset_offset_s`，`missing` 查文件、增益与掩蔽。响度与峰值是技术参数，不证明舒服；没有回听就把 audio 记为 partial 或 not_run。再逐条回答 [发布片语法的成片自查](launch-film-grammar.md#六成片自查逐条回答答不上就返修)，答不上的先返修。

研究别人的成片时，按 [参考片研究](reference-film-study.md) 分级：源码与帧是观察，仪器测量是测量，其余是推断，没听过就写没听过；同源样本不当独立证据，一部片不能证明有效。

## 知识讲解与资讯的审片

使用 `knowledge-music-explainer` 时，按 [科普编排](knowledge-music-direction.md) 分别核领拍方式、知识增量、文字完整出现后的阅读窗、可见结果落点、音乐映射、提示密度及同曲接缝。`explainer_timing_audit.py` 只验证任务表覆盖的排程，不替代实际拍点、像素、音效起音、听感或理解检查。direct无试片确认门禁，最终内部检查与必要返修仍须完成；staged仅在用户指定节点等待。没有真实观众与平台反馈时分别记not_run，不能由机器检查宣称有吸引力。

用了 [知识包](knowledge-pack.md) 时，把 `checks` 当作审片记录的结构：terminology 查术语一致与读音，accuracy 对账真值账本与原始来源，novice_read、peer_read、expert_read 分别请新手、同行和懂行的人读。三类读者各自独立描述“看到了什么、学到了什么、哪里不对”，再对照导演意图；同一个 Agent 自查要写明是自检。没真做过的保持 `not_run`，“看起来对”不能写成 `passed`。

| 改动 | 重验依赖 |
| --- | --- |
| 数字、事实或来源 | 真值账本，所有 derived 与引用它的旁白、字幕、读数；已有 `passed` 的 accuracy 与 expert_read 重置 |
| 术语或读法 | 术语卡、全片用词、读音表与配音；terminology 重置 |
| 层次顺序、桥接或新负荷 | 前后层的桥接、退出测试、重点元素；novice_read 重置 |
| 载体或映射 | 一一映射、四问、断点、L6 的模型边界 |
| 标准版本或核对日期 | 标准状态、引用它的 claim 与术语；超过一年的核对要重查 |

资讯类另查：每条事实的 `as_of`、口径不同的数字是否放在同一把尺上、未确认与有争议的内容是否留在明处。版式整齐不等于已核实。

## 参考对照与有限返修

评审使用本次brief、事实依据、选定参考范围、实际产物和检查目标；先让评审独立描述看见什么，再对照导演意图。按宿主权限与任务授权选择真实可用的独立评审者；由同一Agent检查时明确写自检，不冒称全新评审。没有单独实例时不虚构评审身份。可把评审集中在最难关系的小样、关键粗剪和最终成片，不固定每镜或每次导出都新开一个Agent。

项目内沿已有审片文件记录下表，可由delivery.checks.evidence引用；不强制新建ledger.md或扩展校验器。参考差距与关键瞬间见 [创意导演与编排](creative-direction.md)。

| 记录项 | 要求 |
| --- | --- |
| 对象与范围 | revision、产物哈希、scene／element／beat ID及实际看听区间 |
| 问题与级别 | 时间点或帧范围、阻断／重大／一般、具体观察及对观众的影响 |
| 证据 | 原尺寸帧、连续片段、实测数据或实际试听说明；未测数值记未知 |
| 修改与复验 | 改什么、为何优先、影响哪些依赖、复验方法／范围／结果 |
| 结论与余项 | 已修、未修或待验证；自检／独立评审身份、资源上限与停止理由 |

可用静音复述定位视觉主线问题，但评审者的复述不是用户理解实验；纯音频检查也不能证明完整声画体验。抽帧密度按运动、接缝与风险选取，不固定全片每0.2秒一帧。对照参考时说明具体目标和差距，不能仅给“高级／可以发布”的评价。

先修最大问题，串行复验受影响范围；完整导出后按交付范围再做必要的成片检查，不能只沿用修改前的结论。开始前写清迭代上限和停止条件；未达到要求时记录剩余问题与可用版本，不无限返工。评审建议可交付不等于用户已批准公开发布；实际播放、听审和观众测试各自记账。

## 通用表达兑现与跨镜连续性

按 [创意导演](creative-direction.md) 的关键变化和审美边界核实际片段：产品是否有真实操作后果，知识是否呈现正确条件与关系，资讯是否分清依据与未知，故事是否承接行动，品牌或音乐是否有可辨的发展与释放。记录预期、实际声画证据、缺口和克制理由；不是只数效果，也不是要求每片固定钩子或反转。

沿 [镜头生产统筹](shot-production.md) 检查固定项和可变项。更换镜头后，复验相邻身份／产品状态、空间方向、色光、参考职责、文字空间、声音尾音与下游时间；局部通过不继承为全片通过。只查源码或关键帧时保留观看缺口，未听审保留听感缺口，用户理解及传播效果仍需真实反馈。

## 素材部件与运动范围复核

使用 [素材表演与调度](asset-motion-direction.md) 时分三层记账：源状态能否正确叠回；实际运动极值是否出现缺边、重复主体、错层、错误映射或不可信露底；连续片段中信息、接缝与声音是否成立。像素差异可能来自有理由的新构图，零差异也不能证明移动后没有缺陷；按内容判断，不套统一相似度阈值。

更换源、规范化尺寸、裁切、遮罩、补底、锚点或字体后，重查引用该部件的镜头、相机与标注。仅抽样时记录范围，静态复原或结构通过不升级为全段可看、所有位移可用或已听审。需要循环时复核额外回接时长、跨边界速度及声音，不只比较首尾图像。

## 音乐驱动三维作品

涉及诗词意象、乐器和人物时，补读 [专项检查](poetry-music-world.md)：分清真实声音时间与运动映射，逐项检查收住窗口中的景物、相机与后期；在实际机位检查拨弦接触、双手协同、脸部与衣发。导出、几何数值与同机复现不继承为人物自然度或听感认可。

按 [专项流程](music-driven-world.md) 分别检查预备、触发、接触、峰值、落定和保持，查看关键点前后连续帧并听审，避免只核动画起始时间。强弱与对象、镜头因果对应，密集事件余波另看；候选起音不自动是节拍，帧号一致不自动是有力度。换音乐、片段、速率、帧率后重建受影响数据和画面，失效旧同步/听审记录。保留指定歌曲，不擅自静音或换曲。
