# 匹配剪辑、动作接力与音乐转场

用于音乐视频、产品短片及需要跨镜接力的片段。先沿 [音乐镜头编排](music-shot-choreography.md) 确定声音与事件，再设计关键切口。沿用现有事件卡、稳定 ID 和统一排程，不新增必填格式、第二套时间轴或固定切镜数。音乐视频继续以代码构建可动主场景；图片用于背景、纹理和局部素材，用户明确指定的表现方式优先。

## 先确定这次交接表达什么

为一组接力写清共同的行动、情绪或关系，以及下一镜新增的信息。匹配的物件应在各自场景中有可见用途，或属于本片已经建立的视觉规则；若引入了人物或关系，后续应有相应发展。形状相似可以引导视线，语义联系仍需在画面中建立。

开场先让观众看清主体与一个有辨识度的变化，再让接力规则变得可读；密度、幅度与节奏随实际音乐发展。动作、双语阅读和结果揭示需要足够时间。缩短等待、选择有效动作段或减少重复镜头，优先于为塞进更多镜头而持续加速。慢歌同样设计接力与落点，保留有意的停顿、长镜和余韵。

## 关键切口在制作前写清前后状态

在现有声画事件卡的“下镜联系”与实现备注中补充下列信息；只记录当前转场需要的项目，不要求所有切口逐项填满。

| 判断 | 制作时写清什么 |
| --- | --- |
| 意义与新信息 | 为什么由 A 到 B，共同的行动／情绪是什么，B 揭示或改变什么 |
| 视觉锚点 | 接住哪个主体、轮廓或视线落点；关联对象 ID，必要时记录屏幕位置、尺度与角度 |
| 出镜与入镜状态 | A 最后可见状态与 B 最初可见状态；运动方向、速度趋势和动作阶段怎样延续，或在哪里有意反转 |
| 声音与时序 | 引用已有声音事件；准备、峰值、剪切、转场落定、文字强调分别位于何时，提前或延后有什么作用 |
| 实现与证据 | 对象／相机／遮挡／字幕由哪段实现控制；实际版本、切口帧、前后连续片段和看听结果 |

位置按当前画幅描述或归一化，比较的是最终输出中的投影；换成竖版时重排焦点、空间和双语阅读区。仅在确有连续性需要的地方约束尺度、方向和曝光，不照搬通用百分比或亮度阈值；有意的跳变写明目的并实际观看。

## 按交接条件选择转场

| 方式 | 成立条件 | 代码与画面要兑现的变化 |
| --- | --- | --- |
| 形状／构图匹配 | 共享锚点能被迅速识别，场景有含义联系 | 对象的投影位置、尺度、角度或轮廓相接，环境变化仍能读清 |
| 动作接力 | 切前切后方向、速度趋势和动作阶段兼容 | 下一镜入镜时已经处于承接状态，避免无意停住、倒转或从起点重播 |
| 落定后接力 | 需要看清完整开合、接触或终态，或即将反转运动方向 | 动作先到达清晰结果，在两侧兼容的落定状态交接，再启动下一事件 |
| 遮挡揭示 | 有明确遮挡物，下一镜有值得揭示的信息 | 前景、遮罩与对象有空间归属，遮挡及解除过程实际发生 |
| 尺度／机位接力 | 前镜运动终点与后镜构图或空间关系相接 | 相机或对象抵达目标位置与尺度，后镜承接焦点和运动趋势 |
| 甩镜交接 | 乐段需要能量提升，方向线索可保留 | 出镜加速、切口、入镜减速与落定协调；模糊表现速度，落定对应所选声音 |

直接切换、声音接桥和长镜内变化仍可选。上述方式按段落需要组合，不要求一片用全。动作中切与落定后切都可以成立，按“延续运动”或“看清结果”的目的选择；避免将“动作永远未完成”写成规则。

## 用切口条件驱动代码与音乐时序

1. 从统一排程取得相关声音事件、场景及对象 ID。核对原音源到成片的映射；仅在已适用的区段使用恒速拍网，局部速度变化、唱句、呼吸与旋律锚点继续保留。
2. 为当前事件定义准备、峰值和落定过程，分别安排剪切与转场结束。卡点可以落在接触、揭示、切换或落定上；不默认所有阶段同时发生，也不只核动画开始时间。
3. 用出入镜状态约束场景实现：按需要共享相机方向、对象运动阶段、屏幕锚点或速度趋势。跨镜旋转等连续运动从同一时间进度派生，避免每镜重置产生跳动；有意改变时明确其视觉作用。
4. 让主体、相机、遮挡与字幕拥有可独立控制的状态。先用低成本代码几何体或现有工程预演关键动作和交接，再完善材质与辅助图片；单张整图变换不能证明主体动作已实现。
5. 把绝对时间统一换算为输出帧，记录取整方式及误差，避免每段独立累计拍长导致漂移。换音源、速率或帧率后重验；不为整数帧卡点擅自改动指定歌曲。

音效存在时，对齐文件内实际起音／峰值与目标事件，考虑文件开头的空白和铺垫；增加音效仍遵循原声要求与主次关系。有素材片段时选择有效动作区间，检查首尾空等和锁定尾帧跳变。需要调整节奏时先改动作时长、选段或事件密度，保持所需动作与材质可信。

字幕与镜头共用视线交接：中文词组与紧贴其下方的对应英文作为一组，可跟随当前意象、引出下一焦点或在揭示后落定；具体分组见 [字幕导演](subtitle-direction.md)。切换、模糊和遮挡期间仍核阅读窗，不能因文字图层存在就认定可读。需要时把阅读放在转场前后，保持语义顺序和双语配对。

## 预演与返修围绕实际切口

复用前三秒和关键乐句的预演，让短段覆盖关键切口的准备、交接和落定。可附出镜帧、入镜帧和半透明叠图帮助定位；按需截取有界时间窗，保持原画幅与可辨细节，资源密集操作串行。direct 模式内部完成检查与返修，不增加用户确认节点。

| 检查发现 | 返修方向 |
| --- | --- |
| 两个物件只有形状相似，关系需旁白额外解释 | 补可见用途、行动及后果，或选择更贴合主线的交接对象 |
| 下一镜从静止起步、方向倒转或速度突变 | 修正入镜状态、动作阶段或共享运动；需要反转时考虑落定后切 |
| 主体尺度／位置跳动，视线找不到承接点 | 调整对象投影、构图或相机路径，核最终输出而非只看场景坐标 |
| 转场开始对拍，落定却错开关键声音 | 分开调整准备、切口和落定，不整段盲目平移 |
| 动作来不及读清，或镜尾无意停住 | 重排动作和时长、重选有效区间或减少重复镜头；有意停顿保留其职责 |
| 甩镜遮住词组、英文脱离中文 | 调整成组布局、阅读窗与转场主次，并正常速度阅读 |

连续播放切口前后，核运动、焦点与含义，再结合真实音轨判断峰值和落定。主体曝光与背景变化分开看，有意反差不因全帧平均值变化而自动判错；叠图只辅助位置、大小与轮廓比较，不能证明速度、语义或听感。

已有 `film_probe.py` 的画面差异与 `audio_event_audit.py` 的能量起音仅作候选证据。相似构图切口可能漏检，密集切换可能被合并；已知关键切点优先按排程取样，不以默认检测计数验收。新方法不代表现有脚本已具备跨物件语义匹配或连续运动评判能力。未看、未听分别记录未验证；必要表达未兑现先返修，实际阻塞则交候选并说明缺口。

## 来源与适配边界

灵感来源于 [Sac-Y/match-cut](https://github.com/Sac-Y/match-cut/tree/b51c98f5c795b046ceb1c69396368dbabd88d5d9) 的切口表、动作接力、跨镜运动与检查方法；研究范围见 [来源记录](sources.md#匹配剪辑与音乐转场2026-10-29)。上游主要以生成视频提供主体动作，后期脚本完成剪辑与合成；本库将方法适配到代码动态场景、真实歌曲和空间双语字幕。

其固定 BPM／四拍小节假设、广告结构、横版规格、默认模型与付费服务不成为本库默认。歌词片段按用户指定音源编排，只有授权重组音乐时才裁接重排并回听接缝。保留现有六层模型与七项事件卡，不新增效果配额。本文为方法适配，未导入上游脚本或样片；不继承案例的观看、听审或传播效果结论。
