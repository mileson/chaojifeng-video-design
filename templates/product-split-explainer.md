# 极简左右讲解

模板 ID：`product-split-explainer`。所属大类：`product-promo` 产品宣传视频。精确名称和别名在 `catalog/recipes.json` 维护；这是完整影片编排模板，视觉基础复用 `product-minimal`，不另造渲染引擎。

适合 App、软件与工具的价值介绍。需要连续电影叙事、纯品牌意象或音乐主导时，按主要目标改选或组合已有配方。先读[产品宣传视频方法](../references/product-promo-direction.md)，再将下列内容写入当前作品的轻量分镜或现有计划。

## 输入和可替换项

| 项目 | 怎样确定 |
| --- | --- |
| 产品事实 | 产品入口、名称、平台、版本、目标用户和功能依据；从项目读取，缺少关键事实才询问。给了产品源码和选题侧重点时，按[源码说明片](../references/product-source-explainer.md)建事实账本、取证并映射章节 |
| 可见证据 | 已有截图、录屏、真实作品或可核对的组件状态；至少支持首尾结果和主体主张 |
| 叙事 | 开场结果、少量价值章节、结尾品牌语；不固定为某一产品或功能数量 |
| 视觉 | 白色或近白底、黑色粗标题、少量品牌色；字体、素材、设备外框随品牌和观看尺寸替换 |
| 规格 | 画幅、发布用途、语言、明确时长要求；未指定按产品宣传指南决定 |
| 声音 | 真实旁白、适配音乐及少量必要音效；不绑定某个音色、配音服务或曲目 |

## 必选的首幕、主体与尾幕

| 段落 | 编排 | 通过条件 |
| --- | --- | --- |
| 首幕：结果先行 | 独立全幅构图中，一件核心结果或少量完成作品清楚出现 → 用连续动作或构图接力引出产品名和价值 | 首帧可辨，前三秒有具体所得；后文解释开场结果如何得到；不套主体讲解版式 |
| 首幕可选变体：品牌承诺 | 独立全幅构图中，品牌图形与一句具体承诺 → 尽快落到产品与实际结果 | 来自明确参考或题材需要；不能变成冗长 Logo 片头；与结果先行二选一 |
| 主体：一幕讲清一项价值 | 左侧短标题／一句价值，右侧真实界面、操作或作品；沿同一任务展示输入 → 变化 → 结果 | 口播讲价值，画面证明；操作后保留可读终态，避免只轮换截图和功能名称 |
| 主体变奏：证据需要放大时 | 全屏作品、操作近景、前后对比或多图组合，随后回到主版式或接下一章 | 每次变奏为了看清当前变化，不强制所有镜头左文右机，也不随机换风格 |
| 尾幕：成果与品牌回收 | 操作界面退出 → 独立构图呈现完成作品／核心成果、产品名与自然品牌句 → 画面停留、声音完整结束 | 回收开场图形或作品；最后一个词及尾音不被截断，不重复长介绍；仅有明确转化目标时追加真实行动入口 |

## 左右结构怎样成立

- 新视频未指定时用 9:16（1080×1920）。模板名中的“左右”表达讲解与证据对应，不要求竖版仍分成两个狭窄栏位。竖版优先上方短标题、下方大面积操作／作品，必要时全屏近景或局部左右对比；在分镜阶段按画幅设计，禁止用缩小横版或中心裁切代替重排。
- 用户指定横版或方版时，可从左约 40%、右约 60% 起步，按实际证据调节。左侧保持一项重点，右侧给界面或作品足够面积；每段使用匹配证据的构图，首尾保持独立版式。
- 右侧手机／窗口外框只是可选容器，产品 UI 与成品为主角。容器挤压关键信息时放大局部或取消外框；不要用整个手机缩小截图代替必要近景。
- 标题、主体和底部字幕有各自区域，保留安全边距。字幕沿真实音频出现；不能让旁白、长标题、操作细节同时争抢视线。语言和标点按指南处理。
- 使用短距离位移、淡入、缩放、遮罩或元素接力。先引导注意，再发生变化，最后稳定停留；画面运动适量，不以不停晃动维持节奏。
- 同一任务尽量沿用同一作品。讲尺寸变化就展示布局真实变化，讲参数就展示外观变化，讲保存／分享就展示相关流程；只换标签不算证明。
- 主体用少量短标题、真实界面和底部字幕建立层级，避免重复副标题、装饰性英文和多处口号。讲解推进时明确出现“操作前 → 操作 → 结果”，留白服务焦点，不把主要证据缩在大片空白中。

## 最小分镜卡

每段登记：`稳定镜头 ID / 旁白句 / 起止时间 / 本段价值 / 画面证据与来源 / 版式 / 进入、动作、落定 / 字幕 / 音乐职责 / 检查点`。时间在实际配音后填写；模板中的占位项不进入最终字幕或导出。

编排顺序：开场与结尾草案 → 有依据的主体章节 → 连贯口播 → 真实配音量时 → 镜头与字幕对齐 → 配乐混音 → 导出审片。时长、章节数和镜头比例均随产品调整，不复制案例的固定秒数。

## 交付前逐幕检查

1. 首幕先展示了什么结果？观众能否认出主体？产品名何时出现？
2. 每个价值是否都有真实可见变化，且和旁白讲的是同一件事？
3. 目标画幅的讲解与证据关系是否清楚？需要放大的证据是否获得了近景或全屏？首尾是否脱离主体框架并相互呼应？
4. 字幕是否跟得上声音、不挡 UI、手机尺寸也可读？实际导出缩至手机观看尺寸后，主操作和结果仍可辨吗？
5. 尾幕是否回到成果和产品名，完整听完品牌句并自然结束？
6. 实际导出是否同时保留预期的人声和音乐？观看、听审与未验证范围是否如实记录？

仅修改受影响段落并复验依赖。模板第一次在某个项目制作完成，也只证明该项目、该版本与实际检查范围；不自动宣称模板跨产品验证通过。
