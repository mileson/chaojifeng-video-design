# 音乐导演编排笔记

供歌曲主导视频使用；可合并到项目已有导演笔记，不要求另建同名文件。按本片需要填写，未知标待核实；本模板没有预设剧情、镜头数量、BPM 或切镜间隔。它指导 Agent 的决策，不是可直接渲染的执行格式，也不新增 plan.json 必填字段。

## 1. 真实声音与歌词

- 音源／版本／身份或哈希：
- 源选段、整片规格及 music-cue-sheet 映射：
- 演唱／器乐区间：
- 歌词时间稿路径、精度（句／词／字）、对应音源：
- 转写／对齐方法、已有结果或本次实际尝试、校对状态与不确定区间：
- 按需音频能力：选用入口及任务理由、实际环境／版本、模型缓存、资源和缺项；若补齐则记录安装授权范围、动作及短样验证，沿 [检测与安装指南](../references/audio-capability-setup.md)；不要求三者全装：
- 音乐事件地图路径、听审范围、信号候选和未验证项：
- 锚点层级：段落（关系与情绪走向）、乐句（动作过程）、瞬间（切点／峰值）；引用同一地图中的有效 ID：
- 字幕语言、翻译与用户例外要求：

没有可信歌词时间稿时先探测并尝试可用能力。失败写具体原因与受影响范围，不能将“没有现成稿”当作取消默认字幕的依据；器乐不编歌词。保持源时钟与成片时钟区别，所有执行层从同一有效排程派生。

## 2. 导演构思

- 观众应经历的感受与一句视觉主线：
- 歌曲明确语境／本片自创隐喻（分开记录）：
- 场景、主体、物件与关系；哪些行为或形态变化推进体验：
- 代码构建与素材分工：可独立控制的主体、前中后景、镜头、字幕与转场；关键行为、音乐锚点、实现位置及缺口；图片作为背景／纹理／局部素材的用途：
- 主体正在经历什么、向什么靠近或远离；各段结束后关系改变了什么：
- 贯穿意象及其前态→变化→后态，重复时如何发展：
- 意象与歌曲的关联、画面建立关联的可见线索；哪些解释目前只存在于笔记而需补镜头：
- 风格选择、已有包／自定义方案及与歌曲的适配理由：
- 值得记住的视觉事件、铺垫与后果：

## 4. 声画事件卡（关键事件按需重复）

- 事件 ID／关联 scene、element、beat ID：

| 七项判断 | 本事件的设计与结果 |
| --- | --- |
| 声音锚点 | 层级、源区间与成片时刻、声音特征、证据和核验状态： |
| 情绪目的 | 希望改变什么感受，与当前曲段的关系： |
| 事件前后变化 | 主体／关系前态→具体行为或抽象变化→后态： |
| 视线与运镜 | 先看哪里→引导→发现；当前由场景／文字／镜头谁领衔、下一焦点在哪里；景别、机位及移动怎样揭示变化： |
| 动作峰值 | 准备→积累→抵达／接触／揭示→回落与后果；引用统一排程，哪阶段对应哪声音，偏移理由： |
| 下镜联系 | 下一镜接什么，视线／方向／动作／形状／遮挡／声音／语义如何相接： |
| 实际验证 | 预期事件；产物版本、实际看听区间、观察与证据；状态、缺口、修改及复验，未执行填 not_run： |

实现备注按需写：词／词组的语义分组、场景锚点、出现／强调／停留／交接、英文紧贴对应中文的配对与成组运动；句内变化是精确跟唱还是设计编排；次运动、环境与字幕怎样领衔、让位或承接注意力；资产与工具职责、实现位置、已验证能力和资源限制；显著效果的空间层、附着、驱动、遮挡与光影规则；失败时保留表达目的的替代路线。详细判断沿 [六层模型](../references/music-event-model.md)，不另外建立竞争事件表。

将结果映射到现有 director、scene.intent、beats、motions、audio_cues；工程已有 score.json 时引用它，不手动维护第二套竞争排程。

## 5. 内部预演与成片核对

预演先覆盖前三秒与至少一个关键音乐锚点和相邻镜头接力，检查主体动作、运镜、转场及字幕动效实际发生；再按风险补复杂字幕、转折与显著材质。只用整图推拉、未兑现必要事件时先调整结构并复验，能力或资源阻塞则交候选并写明缺口；复用同一短段，资源密集操作串行。direct 模式内部检查并返修，不另加用户确认。
