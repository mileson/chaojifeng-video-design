# 水与液体构建

先确定镜头要表现液体的什么，再选择形态、光学和运动方法。海浪、咖啡、茶、水洼和玻璃雨水可以共享部分原理，但尺度、边界与运动机制需要分别设计。

## 入口与默认路线

当水或液体本身是主要视觉对象，或镜头强调其形态、光泽、流动、接触变化时，进入本配方。“做一个大海视频”“咖啡液面特写”“雨落水洼”等简短任务也适用；无需用户额外说“三维”或“读取工程指南”。仅在旁白提到海洋、使用海蓝配色或液体只是无表现任务的背景时，不强制进入液体构建。

**先理解工程能力，再选择表现路线。** 先读本方法，再读 [工程指南](ENGINEERING.md) 的“选型前必读”与所选形态模块，然后确定风格和实现。不得先自行声明二维风格，再据此跳过工程阅读。

- 用户明确指定二维／插画／平面风格，或已有作品、指定参考已明确采用该风格时，保持其要求，并在构建卡记录依据。
- 液体为表现主体，且用户与既定作品没有明确平面要求时，默认采用能呈现三维形态与光学响应的液体构建。未提供参考不等于允许降为二维图案。
- 氛围、抽象、极简等词本身不等于二维；可以在三维液体上调整构图、色彩、运动和细节密度。不能添加帆船等主体来回避原有液体表现任务。
- 不为默认路线增加用户确认。先检查已有实现和工具；能力缺失时完成必要实现与关键片段验证，确有阻塞则准确报告，不交付降级作品冒充目标完成。

## 从内容进入构建

把需求写成“元素＋表现重点＋镜头尺度”。例如“咖啡近景，液面轻轻晃动，窗户倒影随波纹变形”，对应有限液面、微小波动、环境反射、杯沿接触；无需增加海浪、海岸泡沫和水下光束。

| 设计层 | 要决定什么 | 观众应看见什么 |
| --- | --- | --- |
| 形态 | 开放液面、有限液面、附着液滴、自由液流或混合体积 | 正确轮廓、厚度、尺度和边界 |
| 光学 | 反射、折射、吸收、散射、微表面与泡沫 | 环境倒影、深浅变化和液体光泽 |
| 运动 | 周期波、局部扰动、流动、汇聚、黏滞或混合 | 有原因、连续且符合尺度的变化 |
| 接触 | 岸边、杯沿、玻璃、入水物体 | 接触线、薄膜、湿润、波纹或水花 |
| 镜头 | 俯视、低掠、微距、水下或跨水线 | 重点清楚，过渡连续，光线适合 |

## 构建次序

1. **锁定表现任务。** 写清液体承担主体、环境、转场还是机制解释，只保留服务该任务的效果。
2. **建立空间与边界。** 先确定轮廓、尺度、液位、深度、接触和相机；不先把一个海面整体缩小再解释为杯中液体。
3. **构建运动层次。** 大形负责轮廓，中层负责可见波纹，微表面负责光泽。局部扰动由事件驱动，历史状态有恢复方式。
4. **让光学响应厚度与环境。** 先准备可反射的明暗结构，再调材质；颜色由光程、吸收与散射形成，避免只改底色。
5. **连接交互。** 泡沫、波纹、水花、湿润、漂浮与同一个运动或接触原因关联。
6. **用镜头放大重点。** 光泽用可读的反射结构，形变用轮廓和侧光，折射用背景参照，混合用颜色与流动层次；避免所有效果同时抢注意力。
7. **验证复刻。** 按实际构图检查连续片段、重复帧、边界和输出，保存可恢复的项目状态。

具体实现顺序、数据依赖和失败定位见 [工程实现与复刻](ENGINEERING.md)，本镜参数与选择记录在 [镜头构建卡](../../templates/liquid-construction.md)。

## 需要一起调整的关系

| 改动 | 一起检查 |
| --- | --- |
| 水深和厚度 | 吸收、透射、水底可见度、焦散与水下散射 |
| 波浪强度 | 轮廓、法线、高光、泡沫、漂浮和岸边响应 |
| 波纹频率 | 网格采样、屏幕像素、法线方差与粗糙度 |
| 液体种类 | 透明度、折射率、吸收散射、表面层和运动阻尼 |
| 物体入水 | 接触时间、波纹起点、水花尺度、后续运动与音效 |
| 相机穿过水面 | 水线、折射、散射、曝光与镜头挂水 |
| 时间速度 | 波形、物理、泡沫、粒子、事件、曝光和声音关系 |

参数联动有物理与艺术两类。要做近似时明确其在镜头内的适用范围；不能把一个艺术控制值解释为真实材料测量。

## 按液体形式演化

### 开阔水面与近岸

开放海面制作加载 [可执行构建配方](OCEAN.md)，先从完整参数预设构建，再按镜头调整并验证；不把历史作品的候选参数当作质量通过。

以大中小波形和微表面建立层次，反射与透射按视角混合。近岸增加水深、传播和浅化关系，让碎浪、退水、泡沫与湿润保持一致。重点验远近细节衔接、浪头方向、岸线接触与时间连续性。

### 咖啡、茶与杯中液体

先建立有限液面、杯沿接触与弯月面，再组织小幅晃动和衰减。用窗口或柔光面的倒影表现光泽，根据厚度调整吸收散射。茶可能保留透视层次，咖啡的透视范围需按外观重新标定；油脂层、奶泡与气泡另外建模。

需要倒入时，增加液流、入杯冲击和液位变化；需要加奶时，增加体积流动与混合方法。它们不能由静态咖啡材质或棕色水面自动产生。

### 雨落水洼

建立浅水轮廓和地面接触，用落点事件驱动波纹与局部水花。事件分布、密度、寿命和重叠有明确控制；倒影随法线变化，边缘逐渐进入湿润地面。低雨量看单个事件，高雨量看整体表面变化，避免无限叠加高成本水花。

### 玻璃雨水

建立液滴厚度、接触角和背景折射，再处理附着、滑落、合并与拖痕。滑落路径受基面、重力和附着关系控制，滴与滴合并后轮廓和体积应连续。镜头挂水可以复用部分表现思路，但不能代替完整玻璃雨水的运动模型。

### 液流、混合与黏稠液体

先判断是否需要分裂、汇聚、体积守恒、黏度或不可见内部流动，选择相应求解或镜头近似。光学可以复用部分原理，运动和形态表示必须适配。倒水、奶液混合、蜂蜜拉丝不作为海面参数变体处理。

## 从便宜的验证走向完整镜头

先用最低足够成本验证轮廓与运动，再逐项增加光学、交互和后期。每轮保留相同机位的前后对照，能判断效果变化由哪项设置引起。表达未改善时保留较简单方案。

镜头只需要平静倒影时，不必启用完整流体模拟；需要近景液体碰撞时，不能用静态贴图和整图推拉替代。成本取舍服从实际画面重点。

## 验收

- 形态：近远景、侧面和运镜时轮廓成立，边界不穿插，细节不跳变。
- 光学：倒影与场景一致，前景不被错误折射，吸收随光程变化，高光不过度闪烁。
- 运动：原因、速度、方向和尺度协调；波纹、水花与接触时刻一致。
- 接触：岸线、杯沿、玻璃和入水物体无明显悬浮缝或穿透。
- 复现：相同初态能重放，随机定位和局部重导按实际需要验证；未做的检查不标通过。
- 输出：实际视频规格正确，关键连续片段兑现镜头要求；文件存在与构建成功不代替审片。

方法、项目实现和实际效果分别判断。配方能指导不同液体的构建，不意味着所有形态已有现成实现。

## 效果目标与技术选型约束

制作前明确目标是二维风格化表现还是三维液体质感。已有参考或上下文要求三维波面、真实光泽、透射与接触时，必须保持这个效果目标，不能因二维方案容易出片而自行降级。无明确风格时按入口的默认路线执行；二维海浪短片不能证明三维液体能力。

所有进入本配方的任务均须在选型前读取 [工程实现与复刻](ENGINEERING.md) 的必读基线和相关形态模块，在构建卡将每项目标绑定到实际实现模块。读过方法、使用相同术语、文件能导出，都不代表能力兑现。

- 开放海面以 GPU 三维波面为主要路线：多尺度频谱波浪、位移网格、法线与水体光学；有白沫或海岸时加入对应生成、历史与接触系统。简化波形只在镜头效果验收成立时采用。
- 波浪轮廓必须由几何或等效三维表面产生；光泽必须响应表面方向、视角和环境；水深颜色必须与厚度或光程有关；泡沫必须有生成原因和消退过程。
- 二维颜色场、移动白线、随机亮点和整图推拉只用于用户或既定作品明确要求的平面风格，不能替代上述能力。更换引擎或提高分辨率也不能替代缺失模块。
- 资源不足时先缩短验证片段、降低预览采样或减少非核心效果，保留决定目标质感的机制；仍无法实现时明确报告缺口，不把降级成片登记为通过。

三维片段制作前必读 [画质构建与排错](QUALITY.md)。低清预演后仍需目标原生分辨率的代表帧与短片验证；全片发现可见缺陷时继续返修，不能以候选片作为完成状态。

## 三维海面的关键镜头验收

先制作约 3—5 秒的原生目标画幅片段。采用能看清浪形轮廓的斜视或低机位，设置有明暗结构的天空／环境和可读高光；避免仅用俯视构图隐藏几何问题。

依次检查：浪形确实起伏；反射随视角和波面变化；深浅与透射合理；白沫随生成原因移动和消退；连续运动没有跳变或明显高光闪烁。镜头包含岸线时另验冲岸、退水和湿润。以匹配的视角、光线与尺度对照目标参考，记录具体差距，不要求照搬参考构图。

检查实际导出连续片段和关键帧，静帧不能代替运动检查。核心项未通过先返修，不进入整片批量渲染；无需为内部验证增加用户确认门禁。画质、运动、复现和媒体规格分别记录，结构测试不能代替视觉通过。
