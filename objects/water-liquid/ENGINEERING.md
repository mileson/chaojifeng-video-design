# 水与液体构建：工程实现与复刻

先让一个关键镜头成立，再将构建过程组织为可重复使用的方法。按实际依赖完成空间、形态、光学、运动、接触与时间控制；每一步都要能回答输入是什么、产生什么、怎样检查。

三维任务在选型后、制作验证片段之前继续读 [画质构建与排错](QUALITY.md)，按全程覆盖、多尺度细节、光学分层和原生质量对照落实。

## 选型前必读

进入液体构建配方时先读本节，再读取第 1—4 节（空间、形态、共享表面、光学）、第 9—10 节（时间与验收）。开放海面另外读“三维海面实施基线”；泡沫、岸线、水下、入水交互分别按镜头补读第 5—8 节。二维需求也先理解上述基线，再记录哪些机制以风格化方式表现；不得用“已选二维”作为不读工程指南的理由。

选型必须产出四项决定，写入已有计划或构建卡，不另建工作流：

1. 效果目标与依据：用户要求、既定作品风格或默认三维路线。
2. 所需能力与实现位置：几何／三维表面、运动、光学、接触、时间系统；没有实现的项标为待实现。
3. 当前工具是否支持：以实际环境与代码为证据，不能仅凭熟悉 Pillow 或易于导出视频就确定路线。Pillow 可用于图像处理与二维内容，FFmpeg 可用于编码；它们不替代三维水体构建模块。
4. 关键片段如何证明能力：镜头、光线、必须可见的变化、连续片段范围和不通过条件。

先复用可核验的实现，缺少模块则补齐实现。不要将本指南当作已有运行库，不把计划中的模块写成已具备能力。实际画面未通过时返回实现与参数排查，不能只修改验收说明、重命名风格或提高输出分辨率。

## 1. 定义空间、尺度与边界

确定世界单位、重力方向、液面基准、深度或厚度、边界形状和相机范围。长度统一；缩放模型后，运动、吸收、纹理频率、碰撞与镜头距离一起核对。

| 形态 | 建模入口 | 边界 |
| --- | --- | --- |
| 开放水面 | 高度场、位移网格或连续曲面 | 远处覆盖、近处细节、岸线和水深 |
| 杯中液体 | 有限曲面或体积的上表面 | 杯壁、液位、弯月面、不穿壁 |
| 水洼 | 浅水区域与地面高度 | 不规则轮廓、湿润过渡、浅水扰动 |
| 玻璃雨滴 | 附着液滴曲面 | 接触角、附着、滑落、合并和厚度 |
| 液流与混合 | 可变拓扑表面、粒子／网格或体积 | 出口、碰撞、体积变化、混合和表面重建 |

高度场适合每个水平位置只有一个表面高度的情况。卷成管状的浪、倾倒液流和分裂液滴不能只靠高度场。按镜头选择物理求解或可控近似，近似必须通过该镜头的形态、运动和接触验收。

## 2. 将液面拆成三层变化

大形控制轮廓和整体姿态，中层控制可见波纹与局部扰动，微表面控制高光与粗糙度。影响轮廓的变化进入几何，小到不影响轮廓的细节主要进入法线和斜率统计。

开放海面可以用频谱叠加并经逆变换获得位移和斜率；有限液面选择满足边界条件的波动模式；雨点按落点事件生成传播波；液滴与液流需不同的几何或求解方式。组合时明确交接量是高度、法线、速度、事件还是缓存。

频谱路线：定义风浪／涌浪能量和方向 → 分配尺度与频率范围 → 固定种子初始化相位 → 按时间演化 → 逆变换 → 输出位移、斜率和必要导数。相邻尺度避免重复计入能量，最细层可只输出斜率。

波长、振幅、周期与方向都有明确单位；波速与波长不能随意独立改变后仍称物理一致。导演慢动作统一控制系统时间或烘焙后的时间映射，不只减慢一个波层。

### 网格和像素的分工

网格承载能被间距解析的位移，法线承担更细的变化。相机靠近时增加局部密度，远处降低几何频率；细节等级切换要检查连续运动。

只对法线做平均会丢失未解析的微波能量。保存斜率均值和二阶矩，以 E[s²]−E[s]² 估计方差并加入有效粗糙度，可以帮助稳定远处光泽；屏幕导数用于抑制像素内法线变化造成的高光闪烁。微波不是越多越好，过量会把水变成刷纹金属。

## 3. 让渲染、物理和接触共享表面

渲染、浮力、水线、泡沫和焦散共享同一个液面定义。合成基础形态、边界波与扰动后，提供一致的高度、位移、法线和必要速度。

存在水平位移时，世界位置与变形前位置并不相同；水高查询要处理坐标对应，不能直接把未变形坐标的高度当最终接触面。视觉与物理采用不同精度时，记录误差并验实际接触。

GPU 计算、CPU 消费时，明确采样点身份、布局变化、模拟时刻、容量、完成信号和失败行为。实时预览可接受可控延迟；逐帧导出固定消费顺序或烘焙结果。队列溢出、旧布局结果和读回失败不能静默沿用旧值。

## 4. 用光线关系建立液体质感

先建立可反射的环境明暗，再调材质。咖啡近景可用窗形亮面建立倒影；清水侧逆光突出薄层透射；雨滴用背景明暗和高光边缘体现厚度。

- 反射比例随视角变化；折射率决定基础反射和折射方向。屏幕偏移强度只是艺术控制，不能作为折射率。
- 光程越长，吸收越明显。透射率可按 T=exp(-σₐ·d) 建立，d 为光程，σₐ 为对应长度单位的通道吸收系数。
- 颜色由透射背景、吸收与散射共同产生。清水、茶、咖啡与奶液分别标定，不能只换表面底色。
- 光学计算用线性颜色；输出转换由一个明确阶段承担，避免重复曝光和色调映射。
- 粗糙度控制高光宽度与倒影清晰度，微表面能量、光源大小和曝光共同检查。

### 屏幕空间与反射方案

屏幕空间折射需要场景颜色和深度。偏移后采到液体前方物体时，要退回或采用合理备用采样，避免前景被拉进液体。画外内容无法直接从当前画面恢复，关键镜头需要额外渲染、环境贴图或其他光线路线。

平面反射需要镜像相机与裁切平面，适合近似平坦的液体基面；波面法线可以扰动反射。容器倾斜、液滴与大曲率液面不能无条件使用同一个反射平面。新增物体须参与正确的反射、深度与阴影通道。

## 5. 让泡沫和湿润有原因与寿命

波面压缩或破碎可作为泡沫生成信号，接触、搅动、气体引入是其他信号。记录覆盖率、年龄、漂移与消退，再用纹理和法线形成层次。

瞬时阈值可能让白沫随波相突然消失；历史恢复能保留消散过程，但需要预热、状态恢复和重放。泡沫覆盖、气泡尺寸和寿命与镜头尺度匹配。海浪白沫、咖啡油脂层和奶泡分别选择生成机制。

岸浪、上岸薄膜、泡沫边和湿润区域共享传播相位及岸形，退水后湿润逐渐减弱。杯沿弯月面、玻璃接触角是另一类边界，不用岸浪参数替代。

## 6. 处理近岸运动与过渡

近岸需要水深或地形函数。根据浅水传播速度和传播时间场组织波前，使其在浅处减速、聚集并随地形转向；浅化增幅后要受水深和破碎条件限制。

长波与近岸波在过渡区平滑交接，避免双重振幅。水平压缩与浪头前倾共享形变预算，防止高度场翻折、自交和薄片错误。不同岸段波前相遇时处理冲突，不将位移无限相加。

验收浪头方向、岸边到达时刻、上岸与退水、泡沫残留和干湿变化。远海成立不代表近岸通过。

## 7. 将水下光纹接回波面与光源

焦散可由折射光束的汇聚和发散估计：将波面小区域投射到水底，比较投射前后面积，得到相对光强。注意斜率插值、覆盖采样与过亮限制，避免细线断为亮点。独立移动的白色纹理不会自动与波面一致。

深度切片可以降低成本，但必须覆盖本镜头真实深度；不能把米级切片直接用于厘米级杯底。水底、道具和光束共用入射位置、波面与阴影。浑浊液体按吸收散射削弱透视和焦散。

水下同时处理光程消光、散射、光束及表面下侧反射折射。相机跨水面时按像素或足够细的镜头区域判断水上／水下，避免整屏突然切换。中间通道若用 alpha 存表面分类，它就不是交付透明度；透明输出单独设计。

## 8. 用事件组织入水与交互

入水事件关联位置、方向、接触尺度、强度和主计划事件 ID。波纹、水花、漂浮响应与声音从同一事件派生，避免错拍。

雨点水洼要管理事件密度、寿命和有效范围，少量固定槽位不能代表任意雨量。落点按固定种子与持续事件序列分布，不能每帧重新随机生成后冒充连续降雨。

漂浮物可用多个采样单元估计浸没体积，计算浮力和相对水速阻力，再积分位置姿态。密度、体积、惯量、采样间距和子步与模型尺度一致。查询延迟、速度估计和最大步长限制会影响运动，低帧率与逐帧导出分别检查。

尾流、互撞、混合、黏度、液面断裂是独立实现工作，不能由已有入水与漂浮效果推导为全部具备。

## 9. 组织可重复的帧流程

1. 从主计划读取本帧相机、光源、参数与事件。
2. 恢复或推进液体和物体状态，消费正确时刻的查询。
3. 计算形态、法线、泡沫、交互和必要焦散。
4. 渲染阴影、反射及液体后方的场景颜色和深度。
5. 绘制液体与接触，再做必要水下合成。
6. 统一后期，输出当前帧并观察实际状态。

共享缓存避免重复计算。循环依赖明确上一状态或子步关系，不由异步完成的偶然顺序决定结果。浮点纹理、多输出目标、多重采样和深度解析在目标引擎实测。

| 时间路线 | 适用情况 | 复刻要求 |
| --- | --- | --- |
| 绝对时间求值 | 可直接求值的波、事件动画、相机 | 同一时间和种子得到同一状态 |
| 固定步长重放 | 泡沫历史、物理积分、累积效果 | 明确初态、子步、预热和查询顺序 |
| 烘焙后读取 | 高成本模拟、反复剪辑与调时 | 保存缓存身份、帧率、范围与采样方式 |

重置覆盖模拟、泡沫双缓冲、速度姿态、接触事件、查询队列、曝光、镜头挂水和抖动计数。仅改 shader 时间无法恢复完整场景。周期波能循环不证明整场景无缝循环。

先验顺序重放，再验倒序／随机定位和区间重导。预览与导出共享动作逻辑，正式输出固定尺寸和质量。慢动作统一处理各系统时钟。

## 10. 保存与验收

用镜头构建卡记录元素目标、形态尺度、边界、几何／材质／运动选择、有效参数及单位、光源环境、相机、主计划事件引用和时间路线。保存最终参数，不能只记调参差值。

实现文件、素材和缓存由现有项目合同管理。适配 ready／render／observe 或同等入口，observe 读取应用后的场景状态。保存重复帧与连续片段；跨设备比较定义有依据的容差，不默认逐像素一致。

低成本验证后再提高细节，检查初始化、内存／显存、帧耗时、磁盘输出和清理。退出时释放本任务纹理、渲染目标、几何、材质、监听与计时器，保留宿主共享资源。

| 症状 | 优先排查 |
| --- | --- |
| 像金属、碎亮点过多 | 微表面能量、方差粗糙度、光源和曝光 |
| 像塑料、颜色平 | 环境反射、光程、透射与散射 |
| 运镜时水纹游动 | 网格频率、mip、坐标和细节等级 |
| 前景轮廓被拉花 | 深度判断、画外采样与备用策略 |
| 岸边断层、泡沫脱节 | 岸形、相位、退水与湿润关系 |
| 咖啡像棕色海水 | 有限边界、尺寸、运动、泡沫与光学 |
| 相同帧结果不同 | 历史状态、查询、随机数和曝光 |
| 雨滴像亮斑贴纸 | 厚度、接触角、背景折射和连续运动 |

结构、实际运行、画面、时间复现、输出和声音分别验收。方法用于指导实现，不能当作所有效果已经自动可用的证明。

## 三维海面实施基线

制作开放海面时沿 [开放海面构建配方](OCEAN.md) 运行和验证。它提供一条具体实现路线；本节的能力要求仍用于判断该路线是否满足当前镜头，缺失项需实现或准确限定。

目标为具有空间起伏、光泽、透射及白沫的海面时，按以下依赖组织自有实现。可复用项目已验证模块；此规范不是现成运行库。

| 模块 | 实现与输出 | 最小验收 |
| --- | --- | --- |
| 波浪模拟 | 多尺度频谱随时间演化，经 FFT 生成位移、斜率及压缩信号；区分几何层与微表面层 | 大中小尺度可辨，方向与速度协调，固定种子可重放 |
| 三维表面 | 位移网格承载轮廓，细节法线承载微波；近远采样与过滤匹配 | 斜视轮廓起伏，运镜无穿帮和细节跳变 |
| 光学 | 环境反射、Fresnel、折射／透射、光程吸收及散射；统一线性光计算与输出 | 高光随法线和视角变化，水深变化有依据 |
| 泡沫 | 压缩／破碎／接触生成，历史状态控制漂移、年龄和消退 | 不呈等距固定白线，不随阈值突然闪灭 |
| 近岸（按镜头） | 水深地形、浅化与传播、远近波交接、冲岸退水和湿润 | 水面与岸线接触连续，泡沫和退水同源 |
| 导出 | 统一时间、种子、固定步长／烘焙、状态恢复和逐帧渲染 | 同帧与区间重导按实际测试记录 |

Web 工程可采用 Three.js 组织场景、相机和渲染，结合自定义 GPU 着色器／计算通道实现上述模块；也可使用已有可验证的三维引擎与离线渲染流程。引擎名称不构成质量证明。具体 API、设备支持和资源预算在项目实现前核实，不把库自带水材质直接等同完整海面系统。

开放海面优先采用频谱路线；少量可控波可用于符合目标的简化镜头，但必须验证其层次与重复感。高度场不能表达完整翻卷、分裂或喷溅：需要时增加适用几何、粒子或流体求解，不能仅提高 FFT 精度。

液体扩展共享光学、事件、时间和验收接口，按形态替换运动：杯中液体用有限边界与衰减模式；水洼用落点事件和浅水边界；玻璃液滴用厚度、接触角和连续合并；液流与混合用适用的表面或体积表示。不得默认所有液体都使用海浪频谱。
